## V44 四盘恢复插件流程（P1，约 5 分钟）

对 **夸克 / UC / 百度 / 阿里** 各走一遍：

1. 点「登录」→ 先进**我们的玻璃引导面板**（不是原生登录页、不是直接弹源网页）。
2. 点「**打开源登录界面**」→ 进源面板；返回后状态**如实**显示「**由源管理·无法读取**」。
3. 确认：**不再出现原生登录入口 / 原生二维码 / 「已登录（XX 原生）」状态**。
4. 四盘行为一致（入口、文案、返回路径）。

- 通过标准：四条全过，且四盘表现一致。
- 证据：`mobile-V44-1.png`（玻璃引导 / 由源管理·无法读取）；按盘可加 `-quark/-uc/-baidu/-ali` 后缀。
- **不通过**：出现原生登录入口 / 直接弹原生二维码 / 显示「已登录（XX 原生）」/ 某盘行为与其他不一致。
- 边界：源面板内部样式由配置源决定；「由源管理·无法读取」是**如实**状态，不算缺陷。

## 判定口径

- **V44 = 回退验收**：网盘入口恢复插件流程 + 状态如实；DEF-2029 关闭口径见 `docs/DEFECTS.md`。
- 失败按 `docs/DEFECTS.md` 模板登记（注明哪个盘、哪一步）。证据：`verify/1.7.0/mobile-V44-1.png`（可加 `-quark/-uc/-baidu/-ali`），截图带状态栏时间、文案要能看清。
