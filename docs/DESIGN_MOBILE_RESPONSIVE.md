# 手机版旋转策略与响应式布局（1.9.38）

> 问题：手机进入播放器后返回，页面仍保持横屏；电视台直播同样。根因是 Activity 级方向没有在离开播放页时强制恢复竖屏，而是回到 `SCREEN_ORIENTATION_USER`（跟随传感器）。
> 范围：手机竖屏页面、点播/直播播放器、电视直播页、平板双方向、TV 布局分支。只写规格，不碰代码。

## 1. 方向策略（唯一口径）

| 场景 | 手机（formFactor=PHONE） | 平板（TABLET） | TV |
| --- | --- | --- | --- |
| 首页 / 发现 / 搜索 / 详情 / 设置 / 片库 / 文件 / 设置类页面 | **固定竖屏** `SCREEN_ORIENTATION_PORTRAIT` | `UNSPECIFIED`（横竖都可用） | 固定横屏 `SCREEN_ORIENTATION_LANDSCAPE` |
| 点播播放器 | 进入：`SENSOR_LANDSCAPE`；退出：**必须 `PORTRAIT`** | 不锁定（`UNSPECIFIED`），布局自适应 | 横屏 |
| 电视台直播列表页 | **固定竖屏** `PORTRAIT` | `UNSPECIFIED` | TV 横屏（原有布局） |
| 直播播放（原生/Web） | 进入：`SENSOR_LANDSCAPE`；退出：**必须 `PORTRAIT`** | 不锁定 | 横屏 |
| 退出到详情并保留小窗 | 仍强制 `PORTRAIT`，小窗在竖屏详情内 | 不锁定 | — |

**必须改掉的现状**
- `MainActivity.java:1151-1154` 手机启动用 `SCREEN_ORIENTATION_USER` → 改为 `PORTRAIT`。
- `PlaybackController.java:921-924`（退出到详情）、`:936-940`（离开播放）、`MainActivity.java:3133-3141`（释放播放层）都用 `USER` → 手机一律改 `PORTRAIT`，在显示返回页之前同步设置。
- `TvLive.java:345-357` 直播列表页手机已设 `PORTRAIT`，保留；进入播放设 `SENSOR_LANDSCAPE`，退出恢复 `PORTRAIT`。
- 不允许任何手机页面在退出后落回 `USER/UNSPECIFIED`；`PORTRAIT` 是手机非播放页的唯一方向。

验收：手机从播放器/直播返回后 300ms 内 `getRequestedOrientation()` 为 `PORTRAIT`，窗口宽<高，无横屏残留。

## 2. 断点与布局分支

优先级：**formFactor（TV → 平板 → 手机） > 宽度断点**；播放器横屏时窗口宽度会 >600dp，但 formFactor 仍是手机，不能误用平板/桌面布局。

| 断点 | 判定 | 布局 |
| --- | --- | --- |
| `isTvDevice` | TV 设备（960×540 基准） | TV 布局，safe overscan 24/18，横屏 |
| 手机 | `smallestWidthDp < 600` 且非 TV | 手机竖屏布局；播放器例外横屏 |
| 平板 | `600 ≤ smallestWidthDp < 960` 且非 TV | 平板布局，横竖自适应 |
| 平板/大屏 | `smallestWidthDp ≥ 960` 且非 TV | 平板扩展布局（4 列/双栏），不进入 TV 布局 |
| 页面内部列数 | 用当前 `windowWidth`（方向确定后） | 手机 2 列；平板竖 3 列 / 横 4 列；TV 由 TV 规范 |

- **不能用 `windowWidth() < 600` 判断手机**：手机播放器横屏宽度必然 >600；先判 `formFactor`。
- 旋转过程中若 `windowWidth` 暂时残留旧值（如直播页刚返回），以 `formFactor` + `isPortrait()` 为准，不使用三栏布局。

## 3. 手机竖屏页面规格（360–430dp 宽）

统一：左右安全边距 **16dp**；顶部状态栏 + 8dp；底部 Dock 64+16+8 → 内容底部 padding **88dp**（无 Dock 页面 24dp）；圆角卡片 16dp；玻璃 `#1AFFFFFF` + 1dp `STROKE_SOFT #1AFFFFFF`。

### 3.1 首页
- 顶部品牌行 44dp；历史记录横滑：卡 **212×84dp**、间距 12、边缘 16；标题 18sp。
- 「今晚看什么」外层玻璃卡左右 16、圆角 16、padding 16/14/16/12；内部 3 张推荐卡横向滑动，卡宽 **120dp**、海报 2:3、间距 10，露出约 2.4 张（不换行挤压）。
- 分类 chips：横滑，高 **34dp**、字 13sp、左右 padding 15、间距 8、边缘 16。
- 筛选三层（紧凑版）：面板左右 16、圆角 16、padding 10/6；L2 行 34dp、字 12sp；L3 单行横滑 chip 32dp、padding 10、间距 8；面板闭合≈46dp、展开≈92dp；不换行大网格。
- 主内容网格：**2 列**，列间距 12，卡宽 `(宽-32-12)/2`，海报 2:3；底部 88dp。
- 历史/发现/首页所有横向滚动条隐藏；滚动边缘不裁切焦点。

### 3.2 发现 / 搜索
- 搜索框高 44dp、圆角 12、左右 16；结果/发现 chips 高 34dp、间距 8、边缘 16；网格 2 列、间距 12。
- 键盘弹出时列表底部 padding = 键盘高 + 16，不遮最后一行。

### 3.3 详情页
- 顶部返回 44dp；海报 **112×168dp**（左 16），右侧标题 20sp 最多 2 行、元信息 12sp。
- 操作按钮：高 44dp、圆角 12，主按钮 `ACCENT` 底 + `BG_DEEP` 字；次按钮玻璃；间距 8。
- 选集：4 列网格，格子高 44dp、间距 8；长线路名单行省略。
- 返回自播放器的小窗：**160×90dp**、右下 16，底边在 Dock 上方 88+12；圆角 12、1dp `#33FFFFFF` 描边、无阴影；可点开，关闭钮 28dp。

### 3.4 播放器（横屏）
- 进入即 `SENSOR_LANDSCAPE`；退出恢复竖屏。竖屏不提供播放器版式（手机播放器只横屏）。
- 顶部：返回 44dp 圆、标题 16sp 单行、右上更多 **44×40dp 胶囊**（3 点 4dp/间距 5dp）。
- 中央三键：同一玻璃胶囊 **212×80dp**（快退 44/播放 64/快进 44，视觉间距 20dp）；焦点只缩 icon 1.04。
- 底部：时间行 32、进度条高 48（热区）、Dock 56；左右安全边距 16、底部安全区 + 8；控制条总高 ≤ 210dp，不遮中央三键。
- 旋转/系统栏：进入 `applyMobileSystemBars(true)`；退出 `false` + 竖屏。

### 3.5 电视台直播列表（竖屏）
- 顶部返回 44dp + 标题 18sp；搜索框 40dp；分类横滑 chips 34dp（全部/央视/卫视/地方/其他），边缘 16。
- 频道列表单列：行高 **48dp**、左右 16；频道名 14sp 单行省略；当前播放 3dp `ACCENT` 左条；收藏心 16dp；底部 24dp。
- 点击频道 → 进入横屏直播播放；BACK → 回竖屏列表并保持分类/滚动位置。
- IPTV 选择器（手机）：面板 **92% 宽 / 78% 高**，左 1/3（最小 104dp）/右 2/3；分类 40dp、频道行 44dp、顶部关闭 32dp；焦点 10% 粉底 + 2dp `ACCENT_SOFT`。

## 4. 平板（600–959dp，双方向）
- 首页：竖屏 3 列、横屏 4 列，列间距 12/16，左右 24；侧栏在 ≥640dp 横屏出现。
- 详情：横屏双栏（左海报/信息 40%，右选集/线路 60%）；竖屏单列，选集 5 列。
- 直播列表：宽度 ≥720dp 用左分类 + 中列表 + 右信息三栏；否则单列。
- 播放器：不锁方向；横竖屏都显示完整控制条，中央三键同 212×80；竖屏时底部控制区可换行，不遮中央。
- 平板不强制竖屏；退出播放器回到进入前方向。

## 5. TV（isTvDevice）
- 固定横屏 960×540 基准，safe overscan 24/18；首页横向分类、筛选/详情/直播按 TV 规范；不进入手机 2 列/平板 3 列分支。
- TV 直播列表原有的左分类/中列表/右信息三栏保留；TV 不响应手机旋转策略。

## 6. 旋转回归验收（必须逐条过）

1. 首页竖屏 → 点播进入播放器（横屏）→ 返回：回到首页，**竖屏**；连续 5 次进出无横屏残留。
2. 详情竖屏 → 播放器（横屏）→ 返回详情（含小窗）：**竖屏**；小窗尺寸 160×90、不遮 Dock；5 次无残留。
3. 电视台竖屏列表 → 进入直播（横屏）→ BACK：回 **竖屏** 列表，分类/滚动位置保持；5 次无残留。
4. 首页/发现/搜索/详情/设置：设备旋转到横屏后仍保持竖屏（手机锁定），返回不出现半横屏布局。
5. 平板：旋转横/竖屏，首页 3/4 列切换、详情双栏/单列切换不塌；退出播放器回到进入前方向。
6. 方向恢复检查：退出后 `getRequestedOrientation()==PORTRAIT`（手机）、`Configuration.orientation==PORTRAIT`、`windowWidth<windowHeight`；无 `USER`/`UNSPECIFIED` 残留，无沉浸式系统栏残留。
7. 快速连点/连续进出（5 次）不出现：半屏黑、控制条残留、小窗叠加、列表列数错乱、TV 布局误入。

## 7. 禁止

1. 手机非播放页使用 `USER/UNSPECIFIED` 方向。
2. 退出播放器只设 `USER` 或依赖用户转回竖屏。
3. 用 `windowWidth()<600` 判断手机（播放器横屏会误判）。
4. 手机竖屏首页/发现/搜索/详情出现 3 列以上主网格或三栏布局。
5. 播放器退出时保留 `SENSOR_LANDSCAPE`、`FLAG_FULLSCREEN` 或沉浸式状态。
6. 直播播放退出后回到横屏列表或丢失分类/滚动位置。
7. 平板被强制竖屏/横屏，或 TV 进入手机/平板分支。

## 8. 验收一句话

手机所有非播放页固定竖屏；点播/直播播放器横屏进入、退出 300ms 内恢复 `PORTRAIT` 且窗口宽<高；连续进出 5 次无方向/布局残留；平板双方向自适应、TV 固定横屏，断点按 formFactor + 600dp 分支而非播放器横屏宽度。
