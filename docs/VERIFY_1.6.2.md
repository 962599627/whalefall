## V43 登录弹窗体验与取数（P1，约 8 分钟）

对 **UC / 百度 / 阿里**（可带上夸克做对照）各走一遍：

1. 点「**App 内登录 XX**」：**百度应自动出二维码**（无需再手动点「登录」）；UC/阿里同理，不应先闪原网页。
2. **加载期间**：只显示我们的遮罩——「**请使用对应网盘 App 扫码登录**」；**不出现原网页**（白底网页/升级页都不许露）。
3. 二维码出现后扫码登录：显示**真实账号名与容量**、文件列表可用（可进目录/返回）。
4. **退出登录**：立刻未登录，重启仍未登录。

- 通过标准：四条全过；任一条失败即 V43 不通过。
- 证据：`mobile-V43-1.png`（加载遮罩，不含原网页）、`mobile-V43-2.png`（二维码 + 登录后账号/容量）。
- **不通过**：百度仍需手动点登录 / 加载时闪原网页 / 遮罩文案不对 / 扫码后无真实账号/容量 / 退出不生效。
- 边界：仅访问用户授权账号；二维码由官方登录流程提供，我们不伪造。

## 判定口径

- **V43**：登录弹窗体验 + 取数一起判；「能登录」但闪原网页或需手点入口 = 不通过。
- 失败按 `docs/DEFECTS.md` 模板登记（注明哪个盘、卡在哪一步、截图对应）。证据：`verify/1.6.2/mobile-V43-1.png`、`mobile-V43-2.png`（按盘可加 `-uc/-baidu/-ali`）。
