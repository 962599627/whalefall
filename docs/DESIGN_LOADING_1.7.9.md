# 播放加载动画 · UI 规范（1.7.9）

> 范围：播放页加载动画（`PlaybackLoading` 全屏层 + `PlayerChrome` 播放器内加载层），素材为 `assets/loading/frame_01..07.webp`（480×480，浅紫底蓝发兽耳少女）。
> 现状问题：帧间隔 125ms 硬切（`PlaybackLoading:27`、`PlayerChrome:50`）、方图 `FIT_CENTER` 直接放在黑底（`PlaybackLoading:72`、`PlayerChrome:369`）、手机 180dp/TV 260dp（`PlaybackLoading:95-99`、`PlayerChrome:672-677`），浅紫方底在黑底上像白方块，且切换过快。
> 依据：`WHALEFALL_DESIGN_SYSTEM.md`（token/动效）；约束：只写本文档，不改代码；不新增颜色（除素材主色取色）；焦点沿用 FocusMotion 2dp 白描边。

## 0. 结论（3 个关键决定）

| # | 决定 | 内容 |
| --- | --- | --- |
| 1 | **是否圆形裁切** | **做圆形裁切**：168/260dp 圆形头像 + 220/340dp 外光晕；边缘用径向暗角过渡，不出现方图直边；圆角 28dp 仅当个别帧主体被圆形裁掉时的备选（待确认）。 |
| 2 | **淡入时长** | 帧间**交叉淡入 140ms**、帧间隔 **280ms**（7 帧循环 1.96s）；加载结束/首帧可见时整层 **150ms 淡出**，不做硬切。 |
| 3 | **是否加进度条** | **做条件进度条**：仅当已知缓冲百分比时，在动画下方显示 168/260×2dp 樱花粉细条；未知百分比不显示，避免假进度。 |

## 1. 构图与融合

### 1.1 手机 / 平板

| 项 | 规格 |
| --- | --- |
| 头像 | **168dp 圆形**（`clipToOutline`/圆形遮罩），CENTER_CROP；静置无旋转 |
| 光晕 | **220dp** 双层径向：蓝紫 `#8FA8FF` 0.35→0.70、粉 `#FFB3C8` 0.10→0.18（低透明）；光晕只在外圈，不盖脸 |
| 边缘融合 | 头像外缘 18% 径向暗角（透明中心→`#000000` 边缘），光晕与黑底之间再叠 1 层 24dp 软过渡；**禁止方图直边、禁止大面积纯白** |
| 位置 | 整体（含光晕）垂直中心在屏高 **46%**；头像+文字组水平居中，文字在头像下 **16dp** |
| 背景 | 播放页全屏层 **`#000000`**；播放器内嵌层沿用 `#66000000` 遮罩，避免全黑盖住视频 |
| 文字区 | 「正在加载」13sp `#F5F7FC`；剧集名第二行 11sp `#A9B7D0`，单行省略；行距 1.35 |

### 1.2 TV（960×540）

| 项 | 规格 |
| --- | --- |
| 头像 / 光晕 | **260dp / 340dp**；圆形裁切、径向暗角同手机 |
| 位置 | 垂直中心 **47%**；文字在头像下 **18dp** |
| 文字 | 只保留「正在加载」**15sp** `#F5F7FC`；剧集名 13sp `#A9B7D0`；**不加动态省略号** |
| 焦点 | 动画与文字**不参与焦点**；失败态焦点落「重试」48dp 玻璃按钮 |

## 2. 动效节奏（重点：慢、有呼吸感）

| 动效 | 参数 |
| --- | --- |
| 帧间隔 | **280ms/帧**（260–300 允许；7 帧一轮 1.96s） |
| 帧间过渡 | **交叉淡入 140ms**（两 ImageView 交替 alpha 0→1/1→0；禁止硬切） |
| 光晕呼吸 | 透明度 **0.35↔0.70**、缩放 **0.96↔1.04**，周期 **2.4s**，ease-in-out 往返 |
| 整体浮动 | **±4dp** 垂直浮动，周期 **3.2s**，ease-in-out；光晕随头像整体移动 |
| 文字省略号 | 「正在加载」每 **400ms** 追加一点（. → .. → ...），1.2s 循环；预留 3 点宽度避免抖动 |
| 进度条 | 已知百分比时显示；数值变化 200ms 线性过渡 |
| 进出场 | 黑底/整体 **150ms 淡入**；加载结束或首帧可见时 **150ms 淡出** |
| 低动效 | `Prefs.REDUCED`/系统减少动画：取消浮动与呼吸，仅保留帧动画；帧间隔不变 |

## 3. 状态

- **加载中**：圆形帧动画 + 呼吸光晕 + 「正在加载」+ 动态省略号（手机；TV 无省略号）+ 可选剧集名/进度条。
- **加载失败**：帧动画停在当前帧并降至 55% 不透明度、停止呼吸/浮动；文字变「加载失败」13/15sp；下方「重试」玻璃按钮 120×44（手机）/160×48（TV），TV 首焦点给重试；显示可读原因一行（11/13sp `TEXT_SECONDARY`，最多 2 行省略）。
- **结束/首帧可见**：整层 150ms 淡出后移除；不闪白、不缩跳。
- **切后台/页面不可见**：停止帧 ticker、呼吸、浮动、省略号计时（`onWindowVisibilityChanged`/`onPause`），恢复可见后从当前帧继续；不得后台耗电。

## 4. 配色 / token

- 背景：播放页全屏 `#000000`；播放器内嵌 `#66000000`。
- 光晕：蓝紫 `#8FA8FF`（素材主色）、粉 `#FFB3C8`（`ACCENT_SOFT`），均低透明度叠加；不使用纯白大色块。
- 文字：`TEXT_PRIMARY #F5F7FC`（主）、`TEXT_SECONDARY #A9B7D0`（剧集名/原因）、`TEXT_TERTIARY #8D9CB6`（弱提示）。
- 进度：轨道 `#33FFFFFF`、已缓冲 `#FF8FB1`（`ACCENT`）；失败态「重试」沿用现有玻璃按钮（白底/玻璃描边，不新增色）。
- 暗角/遮罩：`#000000` 透明度渐变（边缘 18%–24%），不得出现浅紫方块的直线边缘。

## 5. TV 差异

- 尺寸放大（260/340dp）；文字只保留「正在加载」15sp，**省略号去掉**；不做手势/点击提示。
- 动画与文字不可聚焦；加载失败时首焦点落「重试」，BACK 取消加载并回上一级（沿用现有返回逻辑）。
- 帧率与移动端一致（280ms），不因大屏加速；光晕/浮动同参数但幅度不变（视觉上更稳）。

## 7. 复用与待确认

- 复用：现有 7 帧 webp（`assets/loading/`）、`PlaybackLoading`/`PlayerChrome` 两处加载层、`UiTokens` 文字色、`FocusMotion`（失败态重试）、`Prefs.REDUCED` 降级。
- 框架：圆形裁切 + 径向暗角 + 双层光晕；两处加载层共用同一套参数，避免播放页内外不一致。
- 待确认 1：圆形裁切是否切到个别帧的耳朵/发梢（需逐帧截图确认；若切到，备选 28dp 大圆角 + 更强暗角）。
- 待确认 2：进度百分比数据源是否可靠（不可靠则一律不显示进度条）。
- 待确认 3：播放器内嵌小加载层是否也放大到 168dp（现 180dp）；建议与全屏层统一 168dp，避免两套观感。
