## 本版内容

1. **修复动态壁纸盖住播放器**（DEF-2024）：播放页 root（`player-surface`）不铺壁纸，`open/refresh/renderReturn` 兜底同样跳过；退出播放后壁纸立即恢复（动态/静态均验证点）。
2. **检查更新支持选择下载包体**（DEF-2025）：feed 新增可选 `variants`，手动检查出现列表（标准 / arm64 精简 / R8 精简；TV 只显示 TV 包），下载与校验按所选包的 url/size/sha 走；无 variants 的旧 feed 行为不变；自动更新仍用第一项（标准包）。
3. **字体颜色自定义**（DEF-2026）：设置→界面外观/首页与壁纸→字体颜色；9 格色板 + 3 组推荐（月白/亮壁纸深灰/樱粉）+ RGB 滑条（手机可输 HEX），实时预览、恢复默认；主要标题与正文跟随，次要文字自动 70%、弱文字 56%，樱花粉强调色/焦点/状态色不跟随；纳入备份/恢复与默认设置。
4. 含 1.4.4 壁纸生命周期统一修复、1.4.3 播放页点按/铺满与运行日志复制、TV 功能对齐与详情页重排等全部内容。
