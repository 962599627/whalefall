## 本版内容

1. **修复 TV 文件管理「返回不了」**（DEF-2017）：入口 `SettingsScreen` 双重压栈，返回箭头/BACK 又跳回文件页；改为单层 push，返回逐级正常。
2. **TV 详情页重做为平板风格**（DEF-2018）：新增 `TvDetailLayout`（960×540、24/18 安全边、52/48 两栏）：左栏 16:9 预览卡 + 播放浮层 + 「片源·线路」列表；右栏标题/年份地区/演员导演/简介（4 行折叠展开）/2×2 操作区（倒序/简介/收藏/复制降级）/主播放按钮/多季选择/选集 2 列×52dp。DPAD 焦点链完整、返回恢复原焦点；手机/平板详情页不变（仍 `MobileDetailScreen`）。
3. **修复电视台直播页看不到用户壁纸**（DEF-2019）：去掉直播页整页不透明背景，壁纸透出（播放器 overlay 仍不透明）；手机/TV 都生效。
4. 含 1.4.0 全部内容：直播浮层三出口、电视 tab 按钮裁切/靠左、点频道转屏错乱、横屏右侧面板裁切、切 tab 尺寸残留、R8 启动闪退修复；TV 版电视台直播入口与「本机与工具」7 项；首页虚拟化、陕西卫视地址、设置页版本号运行时读取等。
