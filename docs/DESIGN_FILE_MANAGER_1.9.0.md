# 内置文件管理器 · UI 规格（1.9.0）

> 目标：App 内统一文件管理——**本地文件管理** + **网盘文件浏览/直接播放/下载到本地**；替换现有 `FilesScreen` 的单列列表为响应式网格，复用 `UiTokens` 玻璃卡语言、`DownloadManager` 下载状态、`QuarkUcFiles` 网盘凭据逻辑。
> 依据：`docs/WHALEFALL_DESIGN_SYSTEM.md`（下称设计系统）、`docs/LIBRARY_LAYOUT_SPEC.md`（网格）；代码：`FilesScreen`、`PushFiles`（本地根 `files/pushed/`）、`DownloadManager`（WAITING/RUNNING/PAUSED/DONE/FAILED）、`QuarkUcFiles`/`QuarkUcApi`、`CloudZoneScreen`、`NetdiskQrLogin`、`UiIcon`。
> 约束：只写 UI 规格不写代码；不新增颜色（全部引用设计系统 token）；网盘侧只读/可下载，不改源插件 UI；手机/平板/TV 三端。

## 0. 结论（5 条）

1. **结构**：顶部标题 + 存储概览卡 + 「本地文件 / 网盘」分段 + 面包屑/排序筛选 + 响应式网格；底部多选操作栏。
2. **网格**：手机 2 列（<420dp）/3 列（420–599dp）、平板 4 列、TV 5 列；卡片 = 16:10 缩略区 + 2 行标题 + 1 行元信息，固定高度不被内容撑开。
3. **下载**：网盘文件长按多选「下载」→ 选本地目标目录 → 下载队列进度/暂停/继续/取消 → 完成提示并落到本地目录；下载任务在「本地文件」顶部常驻任务条。
4. **网盘态**：4 盘来源标签（App 内/源插件/未登录）；未登录空态进 `PanLoginGuide`；百度/阿里暂只支持登录；源插件凭据只读。
5. **TV**：整块卡片聚焦、OK 打开/长按 OK 多选、BACK 逐级退（多选→文件夹→页面），焦点态 2dp 描边不改布局。

## 1. 页面结构（组件树）

```
FrameLayout 页面（bg BG #0B1220）
├─ AppBar 高 56dp（手机/平板）/ 64dp（TV），左右 16/24dp
│  ├─ 返回圆钮 44dp（仅子目录/选盘态显示；根目录为「文件管理」标题）
│  ├─ 标题 20sp/24sp bold「文件管理」；副题 11.5sp TERTIARY（当前目录名）
│  └─ 右侧动作：新建文件夹 44dp（仅本地）、刷新 44dp
├─ StorageCard 高 76/80/88dp，左右同 AppBar，上 8dp
│  ├─ 左：「存储空间」13sp SECONDARY + 「已用 12.4 GB · 可用 22.6 GB」15sp PRIMARY
│  ├─ 右：「本 App 文件 1.2 GB」11.5sp TERTIARY
│  └─ 底部 2dp 进度条（已用占比）：轨道 #33FFFFFF、已用 ACCENT
├─ Segment 高 44/48dp：本地文件 / 网盘（胶囊，选中 ACCENT 渐变深字）
├─ Toolbar 高 44/48dp
│  ├─ 面包屑 HorizontalScrollView：`文件管理 / 网盘下载 / 夸克`（chip 32dp，当前项 bold 不可点）
│  ├─ 排序 chip 40dp：「名称 ↑ / 时间 ↓ / 大小 ↓」循环
│  └─ 筛选 chip 40dp：「全部类型」→ 视频/图片/文档/其他
├─ FrameLayout 内容区 (weight=1)
│  ├─ RecyclerView 网格（列数见 §2）
│  ├─ DownloadStrip 高 84dp（本地页，仅进行中任务时显示）
│  └─ LoadingSkeleton / EmptyState / ErrorState
└─ SelectionBar 高 56dp（手机）/ 48dp（TV），多选时从底部升起
```

**弹层**：类型筛选 BottomSheet、排序 BottomSheet、下载目标目录 Sheet、文件操作 Sheet（重命名/移动/删除）、重命名输入框、删除确认框、同名覆盖确认框、网盘登录引导（复用 `PanLoginGuide`）。

## 2. 响应式与尺寸

| 断点 | 列数 | 左右边距 | 列/行间距 | 卡片宽（示例 390/844/960） | 缩略区高 | 卡片高 |
| --- | --- | --- | --- | --- | --- | --- |
| 手机 `<420dp` | **2** | 16dp | 12dp | 390：173dp | 108dp | 198dp |
| 手机 `420–599dp` | **3** | 16dp | 12dp | 844：262dp | 164dp | 254dp |
| 平板 `600–1079dp` | **4** | 24dp | 16dp | 960：216dp | 135dp | 225dp |
| TV（`isTvDevice`） | **5** | 24dp（安全边） | 18dp | 960：168dp | 105dp | 195dp |

- 卡片宽 = `(内容宽 − 间距×(列数−1)) / 列数`；缩略区高 = 卡宽×0.625（16:10）；卡高 = 缩略区 + 2 行标题（34dp）+ 元信息（16dp）+ 内边距 12×2 + 间距 8×2。
- 卡片固定高度，标题最多 2 行、超出省略，**不因内容加高**；TV 卡片行高 195 + 18 间距。
- 内容最大宽：手机不设上限（随列数均分）；平板/TV 912dp 居中（超出留白），避免超大窗口卡片过宽。
- 安全区：页面顶部 = `statusBarInset + AppBar`；网格底部留白 ≥ `max(navBarInset,16)+16`；SelectionBar 叠在系统手势区之上；TV 用 overscan 24/18。

## 3. 卡片样式（文件夹 / 视频 / 其他文件）

| 类型 | 缩略区 | 标题 / 元信息 |
| --- | --- | --- |
| 文件夹 | 半透明文件夹图标 44dp（`UiIcon.EPISODES` 或专用 folder），底色 `#1AFFFFFF` 圆角 12 | 名称；`12 项 · 11-09 18:20` |
| 视频 | 深色渐变底 `#0D1A2B→#050B14` + 居中播放圆 36dp（`UiIcon.PLAY_CIRCLE`，ACCENT）；封面可取第一帧/网盘缩略图，取不到用渐变 | 名称 2 行；`12.4 MB · 视频`；缩略区左下 10.5sp 胶囊「12:34 · 1080P」（未知则隐藏），右下「已下载」角标（下载后） |
| 图片 | 缩略图 `CENTER_CROP`（圆角 16 上两角） | 名称；`2.1 MB · JPG · 11-09` |
| 文档/其他 | 类型徽标（MD/PDF/ZIP/APK）44dp 圆角 10 + 文档图标 | 名称；`486 KB · 11-09` |
| 网盘卡片 | 同视频/其他；左上角来源徽标 `App 内`/`源插件`（10.5sp）；右下 32dp 下载圆钮（手机；TV 隐藏，长按 OK 下载） | 名称；大小 · 修改日期 |

- 长名：最多 2 行、`ELLIPSIZE_END`；不显示路径全名（长按操作 Sheet 里显示完整名）。
- 网盘源插件只读：不显示重命名/移动/云端删除入口。

## 4. 交互

### 4.1 本地文件

- 点击：文件夹进入（面包屑下钻、列表刷新）；视频播放；图片全屏预览；Markdown 内置阅读；APK 安装确认；其他文件长按/操作 Sheet 显示路径。
- 长按 500ms 进入多选：卡片左上勾选圆 22dp（选中 ACCENT 底 + 白勾），其余卡片 60% 透明；SelectionBar 出现。
- 多选操作：全选（当前过滤结果）、删除（确认「删除所选 N 项？不可恢复」默认取消）、重命名（仅单选用）、移动（目标文件夹 Sheet）、退出多选。
- 排序：名称/时间/大小循环；文件夹始终排在最前。筛选：全部/视频/图片/文档/其他（文件夹不受筛选影响，始终显示）。
- 新建文件夹：输入 1–32 字，重名提示；写失败 Toast「创建失败，请检查存储空间」。

### 4.2 网盘文件

- 分段切「网盘」→ 顶部 4 盘来源 chips（夸克/UC/百度/阿里），状态点：App 内绿 / 源插件橙 / 未登录灰；选中盘进入目录。
- 点击：文件夹进入；视频直接播放（`QuarkUcFiles` 取直链，带 Cookie/Referer/UA）；其他类型提示「当前仅支持视频播放与下载」。
- 长按多选：下载、退出；源插件只读；App 内也不做云端改名/删除（本轮）。
- 单文件下载：卡片右下 32dp 下载钮（手机）；TV 长按 OK→下载。
- 下载目标：Sheet 选择本地目录（默认 `网盘下载/<盘名>/`，按盘记忆上次目录；可新建文件夹）；显示「可用 22.6 GB · 文件 1.2 GB」；空间不足禁用「开始下载」并提示。
- 同名冲突：覆盖 / 自动重命名（`名称 (1).mp4`）/ 取消，默认取消。

### 4.3 下载队列（复用 DownloadManager 状态）

- 下载任务在「本地文件」顶部 DownloadStrip 展示：缩略图 40×40、名称 13sp、状态行 11sp（`下载中 42% · 1.2 MB/s` / `已暂停` / `已完成` / `失败`）、2dp 进度条、右侧 32dp 暂停/继续、取消。
- 网盘卡片同步显示 2dp 进度条与百分比；下载中点击卡片弹 Sheet「暂停/取消/查看目标目录」。
- 完成：Toast「已下载到 文件管理/网盘下载/夸克/xxx.mp4」+ 卡片「已下载」角标；本地页自动刷新；失败：状态红字 + 「重试」。
- 切后台/离页：下载继续（前台服务能力沿用现有），回来恢复进度显示。

### 4.4 TV 遥控

- 首焦点：内容区第一张卡片；空态→主动作按钮（去登录/打开管理员后台）；未登录网盘→「去登录」。
- 方向键：左右在行内移动（行尾停住）、上下跨行（同列）；到首行再上→排序/筛选 chip→分段→AppBar 返回/新建；到末行再下→SelectionBar（多选时）。
- OK：打开文件夹/播放/预览；**长按 OK 1.2s** 进入多选；多选下 OK 勾选/取消。
- SelectionBar：左/右在「全选/删除（或下载）/退出」间移动；执行后退出多选并 Toast 结果。
- BACK：多选→退出多选；子目录/网盘目录→上一级；根目录→离开页面；弹层→关弹层。焦点返回进入前卡片。
- 焦点态：2dp 白描边 + 现有 1.02×（FocusMotion），不改变卡片尺寸；滚动时焦点卡完整可见。

## 5. 状态（空 / 加载 / 失败）

| 状态 | 展示 |
| --- | --- |
| 本地加载 | 2 行骨架卡（与真实卡片同尺寸，`SURFACE_1 #141C2A`，不闪烁） |
| 本地空 | 64dp 玻璃圆 + 17sp「还没有文件」+ 13sp「通过管理后台上传，或从网盘下载」+ 48dp「管理员后台」 |
| 本地失败 | 17sp「读取目录失败」+ 13sp 原因 + 48dp「重试」；不白屏 |
| 网盘加载 | 骨架卡 + 顶部 `正在读取<盘名>文件…` 13sp；可取消返回 |
| 网盘未登录 | 64dp 云图标 + 17sp「未登录<盘名>」+ 13sp「登录后浏览、播放与下载」+ 48dp「去登录」（进 PanLoginGuide）+「返回」 |
| 网盘空目录 | 17sp「这个文件夹是空的」+ 13sp「换一个目录，或稍后刷新」 |
| 网盘失败 | 17sp「读取网盘失败」+ 13sp 原因 +「重试」/「重新登录」；不显示他人数据 |
| 下载失败 | 任务条红字「下载失败：原因」+「重试」；保留已下载部分不覆盖原文件 |

## 6. 交互流程（文字）

**A. 本地浏览**：进入「文件管理」→ 默认本地根目录 → 点击文件夹（面包屑追加、内容刷新）→ 点击视频播放/图片预览/Markdown 阅读 → BACK 逐级返回根目录 → 再 BACK 离开页面。

**B. 网盘下载**：切「网盘」→ 选盘（未登录则「去登录」→ PanLoginGuide/扫码）→ 进入目录 → 长按视频 →「下载」→ 选择目标目录（默认 `网盘下载/<盘名>`）→ 校验空间/同名 → 加入队列 → 本地页顶部任务条显示进度 → 可暂停/继续/取消 → 完成 Toast + 卡片「已下载」→ 本地目标目录出现文件。

**C. 多选整理**：长按卡片 → 多选态 → 勾选多张 →（本地）删除/移动/重命名（单）或（网盘）下载 → 确认 → 执行并 Toast「已删除 N 项 / 已移动 N 项 / 已加入下载 N 项」→ 退出多选。

**D. TV 遥控**：进入文件管理器 → 首焦点第一张卡 → 左右/上下选卡 → OK 打开文件夹/播放 → 长按 OK 多选 → 下到 SelectionBar → 执行 → BACK 退出多选/返回上级/离开页面。

## 7. 边界与不做

- 不做：本地文件云端同步、网盘云端重命名/删除/移动（本轮只读+下载）、跨网盘复制、视频转码、文件夹递归下载（首版仅文件；文件夹下载待确认）。
- 网盘支持范围：夸克/UC 可浏览+播放+下载；百度/阿里当前仅登录/退出（沿用 `CloudZoneScreen` 限制，页面显示「仅登录，暂不支持浏览」）。
- 本地存储上限：上传 200MB 限制沿用；**网盘下载不套 200MB 限制**，按可用空间校验；下载目标限定 App 私有目录。
- 隐私空间：不展示网盘登录与下载记录（沿用现有策略）；下载任务在隐私空间暂停/不可见。
- TV 不显示触屏小按钮（下载圆钮、⋯）；所有可点元素 ≥48dp；数字/字母输入用遥控键盘，不弹系统软键盘。
- 待确认：文件夹整目录下载、网盘视频原画/转码选择、下载完成后的自动打开开关、平板横屏是否 5 列（本规范按 4 列）。
