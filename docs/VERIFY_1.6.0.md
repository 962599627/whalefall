## V41 UC / 百度 / 阿里 原生直连（P1，E8 Phase 4，约 10 分钟）

对 **UC、百度、阿里** 三个盘，各走一遍：

1. **App 内登录**：应弹网盘自己的**二维码/官方登录页**并完成登录（不是手动标记、不是源面板）。
2. **真实账号/容量**：登录后显示真实账号名与容量（来自官方接口，可与官方 App/网页对照）。
3. **文件列表**：能列出真实文件（文件名/大小/时间），可进目录、可返回。
4. **退出登录**：退出后立刻变未登录，**重启 App 仍未登录**。
5. **失败路径**：接口不可用/风控/需验证时，必须显示**真实错误**（如「需要验证码」「接口失败」），**不得显示已登录**。

- 通过标准：**三盘全过**；任一盘只能登录不能读数据、或失败时伪装已登录 = 不通过。
- 证据：`mobile-V41-uc.png`、`mobile-V41-baidu.png`、`mobile-V41-ali.png`（各含账号/容量或文件列表）；失败时补错误提示截图。
- **不通过**：某盘无法登录 / 登录后无真实账号名或容量 / 文件列表空或假 / 退出不生效 / 失败时显示「已登录」。
- 边界：仅访问用户自己授权账号，不内置/不代理他人资源；**网盘接口/风控变更属外部风险**，失败按真实错误展示即可，不要求绕过。

## 判定口径

- **E8 Phase 4 → V41**：四盘（含已通过的夸克）都能真实登录+读数据才算完成；缺一盘记「未完成/未覆盖」。
