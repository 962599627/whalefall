## V48 片头片尾记忆（#5）

- **前置**：选一部剧，第 1 集手动标记片头（如 90s）与片尾（如 30s）；第 2 集不标记。
- **步骤**：①进第 1 集看是否自动跳过片头 ②播到片尾看是否跳下一集/回列表 ③进第 2 集确认不误跳 ④切换剧集再回来 ⑤重启后检查标记是否还在。
- **期望**：跳过片头**误差 ≤2s**（先探针后 seek，不先出声再跳）；片尾按设置生效；未标记集**不误跳**；记忆**持久化**、按影片/剧集正确生效。
- **手机/TV 差异**：TV 跳转后焦点/连播正常；手机横屏与竖屏切换后再验一次跳转。
- **证据**：`mobile-V48-1.png`（片头标记）、`mobile-V48-2.png`（跳过后的位置）、`mobile-V48-3.png`（重启后标记仍在）；TV 加 `TV-V48-1.png`。
- **不通过**：误差 >2s / 未标记集误跳 / 重启丢标记 / 跳转后卡死。

## V49 搜索聚合（#6）

- **前置**：≥2 个搜索源能返回同一影片；另备 1 个慢源/坏源。
- **步骤**：①搜索关键词 ②看聚合结果（去重、来源数）③点结果切换源 ④选可播源起播 ⑤再切到慢/坏源。
- **期望**：同一影片**去重合并**并显示来源数；切源后**真的能起播**（不是只换标题）；坏源有可读提示；不重复、不把不同影片错并；分页稳定不丢结果。
- **手机/TV 差异**：TV DPAD 选源、切换后焦点不丢、BACK 回结果列表。
- **证据**：`mobile-V49-1.png`（聚合结果+来源数）、`mobile-V49-2.png`（切换源后起播）；TV 加 `TV-V49-1.png`。
- **不通过**：重复条目 / 切源不可播 / 坏源静默失败 / 不同影片错合并。

## V50 片库批量 / 收藏分组 / 本地搜索（#7）

- **前置**：片库 ≥10 条含可删除项；建 2 个收藏分组；本地标题可搜。
- **步骤**：①多选 ≥3 条 → 删除 → 看二次确认 ②取消/撤销 ③收藏分组重命名、移入条目 → 重启 ④片库内搜索关键词 → 试无结果/空关键词。
- **期望**：批量删除有**二次确认**且可**撤销**；取消确认不删；分组名与成员**重启后保留**；本地搜索即时命中（大小写/别名）、无结果有**空态**、清空恢复全部。
- **手机/TV 差异**：手机长按多选；TV 用焦点+OK 多选、BACK 取消选择并保留已选。
- **证据**：`mobile-V50-1.png`（多选+确认）、`mobile-V50-2.png`（撤销后）、`mobile-V50-3.png`（重启后分组）、`mobile-V50-4.png`（搜索空态）；TV 加 `TV-V50-1.png`。
- **不通过**：无二次确认 / 不能撤销 / 重启丢分组 / 搜索无空态或卡死。
