## V31 网盘登录走我们的 UI（P1，DEF-2027，约 3 分钟）

1. **手机**：设置/首页 → **网盘与账号** → 对「我的夸父 / 优汐 / 嘟嘟 / 阿狸（停用中）」点「**登录**」。
2. 期望**先出现 App 玻璃风格登录面板**（不是白底绿/红块原始框），面板里能看到「**打开源登录面板**」「**我已登录，刷新**」。
3. 点「打开源登录面板」→ 源面板应**套在我们的容器/标题栏**里；完成登录返回后点「**我已登录，刷新**」→ 状态更新（已登录/凭证可见）。
4. **TV**：同样路径用遥控操作一遍（DPAD 可达、BACK 正常返回、状态不丢）。

- 期望：入口是我们的 UI；能进源面板也能回来；刷新后状态正确。
- 证据：`mobile-V31-1.png`（手机玻璃面板）、`TV-V31-1.png`（TV 玻璃面板）；可选 `mobile-V31-2.png`（刷新后状态）。
- **不通过**：点登录直接弹白底原始框 / 玻璃面板不出现 / 「打开源登录面板」点不开 / 返回后状态不刷新 / BACK 卡死。
- 边界：**源面板内部的控件样式由配置源决定**，只要「套在我们的容器/标题栏里」即可，源自己写的控件样式**不判失败**。
