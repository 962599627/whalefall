## 3. 构建环境（每次会话重开都要先确认/重建）

> **环境重置实测（2026-11-09 22:15）**：`/usr`（JDK）、`/tmp/aosp`、`/usr/x86_64-linux-gnu` 都会被清空。恢复步骤：`apt-get update && apt-get install -y openjdk-17-jdk-headless qemu-user-static`（若 dpkg 卡在 `update-alternatives: /usr/share/man/man1… No such file`，先 `mkdir -p /usr/share/man/man1 /usr/share/man/man8 && dpkg --configure -a`）；重新下载解压 `platform-35_r02.zip`、`build-tools_r35_linux.zip` 到 `/tmp/aosp`；x86_64 运行库用 `archive/mirrors 的 amd64 deb（libc6/libstdc++6/libgcc-s1/zlib1g）解包到 /usr/x86_64-linux-gnu` 并建 `lib`/`lib64` 软链。工作区 `/root/workspace` 与 git 不受影响。
