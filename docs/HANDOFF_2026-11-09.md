## 3. 构建环境（每次会话重开都要先确认/重建！）
- JDK：`/usr/lib/jvm/java-17-openjdk-arm64`（环境重置后可能丢失，`apt-get install -y openjdk-17-jdk-headless` 恢复）。
- 工具链：`/root/workspace/toolchain/sdk`（aapt2/aapt/zipalign 是 shell wrapper，指向 `/tmp/aosp/bt/android-15/*`，**通过 qemu + 显式 ld-linux 运行**）；`/root/workspace/toolchain/gradle-8.13` 用于 Gradle 构建（AGP 8.7.3 已验证）。
- Android 平台：`/tmp/aosp/android-35/android.jar`（解压自腾讯镜像 `platform-35_r02.zip` + `build-tools_r35_linux.zip`）。**/tmp 每次会话可能被清空**，被清后要重新下载解压，并确认 wrapper 路径一致。
- `/tmp` 被清后重建步骤：
  1. `apt-get install -y openjdk-17-jdk-headless qemu-user-static`
  2. 从 `https://mirrors.cloud.tencent.com/AndroidSDK/` 下 `platform-35_r02.zip`、`build-tools_r35_linux.zip`，解压到 `/tmp/aosp`（平台解压出 `android-35/`，build-tools 解压出 `android-15/`，移动到 `/tmp/aosp/bt/android-15`）
  3. x86_64 运行库：解压 Ubuntu amd64 的 libc6/libstdc++6/libgcc-s1/zlib1g 到 `/usr/x86_64-linux-gnu`，并建 `lib`/`lib64` → `usr/lib`、`usr/lib64` 的软链
  4. wrapper 内容（aapt2/zipalign/aapt 同构）：`exec /usr/bin/qemu-x86_64-static -L /usr/x86_64-linux-gnu /usr/x86_64-linux-gnu/usr/lib/x86_64-linux-gnu/ld-linux-x86-64.so.2 /tmp/aosp/bt/android-15/<tool> "$@"`
- 构建命令：
```bash
cd /root/workspace/marcomovie
export MARCOMOVIE_JDK=/usr/lib/jvm/java-17-openjdk-arm64 \
       MARCOMOVIE_BUILD_TOOLS=/root/workspace/toolchain/sdk \
       MARCOMOVIE_ANDROID_JAR=/tmp/aosp/android-35/android.jar \
       MARCOMOVIE_PREBUILT_CATPAW_DIR=/root/workspace/native-prebuilt/catpaw \
       MARCOMOVIE_PREBUILT_DEADLINE_DIR=/root/workspace/native-prebuilt/deadline
python3 scripts/build_android.py
cp -f dist/WhaleFall-1.2.2-android-mobile.apk dist/WhaleFall-1.2.2-*.sha256 "/sdcard/Download/DSH-Go/鲸落/"
```
- 所有 bash 必须 `sandbox_permissions: "danger-full-access"`（proot 无沙箱后端）。

## 4. 关键代码位置
- `MainActivity.java`：启动/整页切换、播放页、崩溃日志、壁纸、设置入口、toast（系统 Toast）
- `MobileShell.java`（最大）：5 tab 外壳 + 设置 10 页 + 片库（`renderMyTab`/`buildLibraryList`/`MyListAdapter`）+ 首页（`renderHomeTab`，仍是 ScrollView+LinearLayout 网格，待虚拟化）
- `TvLive.java`：电视台直播列表 + 频道管理 + WebView 播放页 Player（方向按 `a.formFactor`、chrome 显隐、纯黑 token）；`ChannelManagerScreen.java`：频道管理（筛选/隐藏/改址/粘贴复制/全量配置导入导出）
- `PlaybackController.java`/`PlayerChrome.java`/`PlaybackControls.java`：点播播放器（默认画面比例 `Prefs.ASPECT=4` 裁切填充）
- `FilesScreen.java`/`MarkdownScreen.java`/`ChannelManagerScreen.java`：已改为 `a.open(new Screen(...))` 压栈，返回不再退出 App
- `ImageLoader.poster()` 会 `image.setTag(地址)`，**任何 RecyclerView holder 不得靠 tag 找子视图**
- 设计规范：`docs/TV_LIVE_RESPONSIVE.md`、`docs/LIBRARY_LAYOUT_SPEC.md`、`docs/WHALEFALL_DESIGN_SYSTEM.md`（以实际文件名为准）、`docs/ANDROID_AUDIT_2026.md`、`docs/GRADLE_MIGRATION.md`、`docs/BASELINE_PROFILE.md`
- 本轮团队产出：`docs/SPRINT_BOARD.md`、`docs/STATUS_2026-11-09.md`、`docs/PRODUCT_BACKLOG.md`（如已生成）
