# 体验设计 · 3 个新功能建议

> 背景：鲸落 Android 1.7.10 已发布（新播放加载动画已落地）；本文件只写产品/体验建议，不碰代码，不含源插件 UI 改造。
> 工作量口径：S ≤1 人日 / M 2–4 人日 / L >4 人日（单端 UI + 数据链路）。

1. **智能片头片尾记忆** — 体验价值：同一部剧首次手动标记片头/片尾，之后每集自动跳过，追剧少按十几次快进，减少反复拖进度条的打断感。
   - 手机：播放中长按/滑杆一键标记，详情页显示「已记忆片头 1:25 / 片尾 2:10」；TV：遥控长按 OK 标记，自动跳过并 3s 轻提示「已跳过片头」；工作量：**M**。
2. **观看历史按剧集折叠** — 体验价值：同剧多集合并为「看到第 3 季第 5 集 · 32%」一张卡，历史/继续观看不被同剧多集刷屏，找片更快。
   - 手机：历史列表折叠，点开展开集数；TV：首页「继续观看」横向大卡，OK 直接续播；工作量：**S**。
3. **搜索结果跨源聚合去重** — 体验价值：同名影片跨源合并为一张卡，详情内切换来源/线路，减少重复结果与「点了不能播」的挫败感。
   - 手机：结果卡标注「3 个来源」，详情内可选源；TV：大字号单列结果 + OK 自动优选可用线路；工作量：**M**。
