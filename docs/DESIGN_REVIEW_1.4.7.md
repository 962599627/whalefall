# 网盘登录引导面板 · UI/UX 规范（1.4.7）

> 目标：用户点网盘「登录」时先出现我们自己的玻璃引导面板，**不再直接弹源提供的白底原始框**；确需源登录页时用我们的容器包住。
> 依据：`WhaleFall Design System`；代码：`PanLoginGuide`（现引导面板）、`AccountPanel`（网盘与账号）、`SourceController.sourceAction()`、`UiTokens`、`FocusMotion`。现状：引导面板已存在（`PanLoginGuide.show`），但存在入口绕过/直接调 `LoginShow` 的路径，且源面板本身无法改样式。
> 约束：只写本文档；不改代码/其他 docs；不新增颜色字号；焦点沿用 FocusMotion 2dp 白描边；源内样式不可控部分如实说明。

## 0. 结论（2 个关键决定）

| # | 决定 | 内容 |
| --- | --- | --- |
| 1 | **源登录容器** | 双轨：**网页型源**套我们的玻璃容器（标题栏 + 关闭返回 + 加载/失败态，内部样式不控）；**原生 Dialog 型源**无法包裹，只能前置确认 + 返回后自动刷新。**所有「登录/管理」入口先走我们的引导面板，禁止直接调 LoginShow**。 |
| 2 | **原始面板入口** | **保留但降级为次级**：引导面板内「高级 · 直接打开源原生登录（样式由源提供）」+ 确认弹窗，不作为主按钮/首焦点。理由：部分源只有原生面板能完成登录，删除会断功能。 |

## 2. 源登录面板容器要求

- **网页型（WebView/网页登录页）**：进入我们的容器——背景深色遮罩 + 顶部 48/56dp 标题栏（返回 44 +「登录 · <源名>」17sp + 关闭 48）+ 内容区；加载时 22dp 粉环 + 13sp「正在加载源登录页…」；失败态「源登录页加载失败」+ 重试/关闭。容器**只包外框**，网页内部白底/绿红按钮无法改。
- **原生 Dialog 型**：系统级弹窗会浮在我们的容器之上，**无法包裹**；只能前置我们的确认卡（标题/说明/「继续打开」/「取消」），确认后暂时收起引导，源面板关闭后回引导并自动刷新状态。
- **强制顺序**：所有「登录/管理/登录凭据配置」入口 → 我们的引导面板 →（用户明确点「打开源登录面板」）→ 确认卡 → 源登录。禁止任何入口直接调用 `LoginShow`。
- **能控**：入口、外框/标题栏、关闭与返回、加载/失败态、状态点、刷新、焦点、背景与圆角。
- **不能控**：源内 HTML/CSS（白底、红绿按钮、二维码尺寸/颜色）、原生 Dialog 的层级/尺寸/文案/输入控件、登录协议与结果；只能通过返回后刷新读取结果。
- **返回**：容器关闭后回引导面板并刷新该网盘状态；不退出 App；源面板被系统返回键关闭时同样回引导。

## 3. TV 焦点顺序 / 首焦点 / BACK

1. 首焦点：**首个「未登录」网盘行**；全部已登录→「我已登录，刷新状态」；无网盘源→「导入配置」。
2. 方向键：上下在 4 行间移动；从末行下→主操作，再下→刷新→关闭；左右在按钮行内移动（单列时忽略）；OK 打开登录引导/执行操作。
3. 行内「登录/管理」小胶囊不是独立焦点：**整行聚焦 + OK**，避免 32/44dp 小目标。
4. BACK：引导面板→关闭并把焦点还给入口（HomeDock 网盘图标 / 设置「网盘与账号」行）；源容器内→关闭容器回引导；原生源面板的 BACK 由源处理，随后回引导刷新。
5. 焦点态：FocusMotion 2dp 白描边 + 1.02–1.03×，不改行高/内边距；滚动时焦点行完整可见（上下留 16dp）。

## 4. 复用 / 待确认

- 复用：`AccountPanel/PanLoginGuide` 玻璃壳、4 网盘 `DRIVES`（别名/提供商/品牌色）、状态检测（`scanCredentials`/`driveHasLocalCredential`）、`FocusMotion`、关闭按钮规范。
- 需改：标题统一「网盘与账号」+ 当前源名；所有登录入口统一到引导面板；TV 焦点链；网页型源加容器。
- 待确认 1：哪些源 `LoginShow` 是网页型（可套容器）、哪些是原生 Dialog（只能预提示）——需开发按源实测标注。
- 待确认 2：TV 源登录页是否一定显示二维码；若源只支持手机 App 扫码而电视无摄像头，给「请在手机端登录后回电视刷新」兜底文案。
- 待确认 3：引导面板是否合并进 `AccountPanel`（少一层弹窗）；建议保留独立面板，入口一致即可。
