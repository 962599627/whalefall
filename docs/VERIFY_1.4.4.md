## V27 壁纸全程不丢（P1，DEF-2023，约 8 分钟；静态/动态各走一遍）

**准备**：先在设置里确认壁纸类型（静态 / 动态），看清自己设的那张图/那段动画长什么样。

1. 首页 → **详情页** → **选集页** → 返回首页。
2. 进**播放** → 退出回首页。
3. 依次切 **5 个 tab**（首页 / 直播 / 电视 / 片库 / 设置）。
4. **设置内页** → **文件管理** → **阅读器** → 返回。
5. **旋转一次**（竖 → 横 → 竖）。

以上每一步都看背景：应是用户设置的那张/那段壁纸，**不能变纯色深蓝渐变**；动态壁纸要真的在动。

- 期望：全程壁纸一致、不丢、不退化成纯色；文字与 glass 面板仍可读。
- 证据：`mobile-V27-1.mp4`（60s，覆盖全流程）+ 关键页截图 `mobile-V27-2.png`（首页）、`mobile-V27-3.png`（返回后）、`mobile-V27-4.png`（旋转后）。
- **不通过**：任一页面变纯色 / 壁纸消失 / 动态壁纸不动 / 旋转后丢 / 两页壁纸不一致。
- 异常时补：设置 → 运行日志里 **`Wallpaper` 开头**那条日志截图 `mobile-V27-log.png`。
