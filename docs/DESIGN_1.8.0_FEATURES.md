# 鲸落 1.8.0 合并功能设计规范（#5/#6/#7）

> 范围：只写设计规范，不碰代码。覆盖 ①#5 智能片头片尾记忆 ②#6 搜索跨源聚合去重 ③#7 片库批量整理 + 收藏分组 + 本地搜索。
> 依据：`docs/WHALEFALL_DESIGN_SYSTEM.md`、`docs/LIBRARY_LAYOUT_SPEC.md`；代码：`PlaybackControls`（跳过逻辑）、`MobileDetailScreen`/`DetailScreen`、`GlobalSearchScreen`（TV 搜索）、`MobileShell.renderSearchTab/MyListAdapter`、`Favorites`/`WatchHistory`。焦点沿用 FocusMotion 2dp 白描边；不新增颜色 token；拿不准标「待确认」。

## 0. 共用原则

- 三端：手机 390dp 竖屏为主、平板沿用现有网格、TV 960×540 遥控；TV 不做触屏小按钮与手势提示。
- 焦点：TV 卡片/行整块可聚焦、OK 执行、长按 OK 次级操作；焦点态不改布局；BACK 先退当前模式（多选/键盘/弹层）再退页面。
- 空/加载/失败态必须可退出、不白屏；操作失败用 Toast/确认框，不静默。
- 所有新增数据本地存储，纳入备份/恢复；不改变源插件 UI。
- 文案统一中文，标题 17sp/正文 15sp（手机 13–15sp）、次要 11.5–13sp；TV 标题 20–24sp。

## 1. #5 智能片头片尾记忆

### 1.1 组件结构

| 组件 | 手机 | TV |
| --- | --- | --- |
| 标记入口 | 进度条**长按 500ms** → 玻璃浮层；「更多工具 → 片头/片尾」同入口 | **长按 OK 1.2s** → 同一浮层；无进度条长按 |
| 跳过设置浮层 | 宽 360dp、圆角 22、标题「跳过设置 · <剧名>」17sp；两行状态「片头 01:25」「片尾 02:10」；按钮：标片头为当前 / 标片尾为剩余 / 清除本剧记忆 / 关闭（44dp） | 宽 560dp、标题 20sp；按钮 48dp；首焦点「标片头为当前」，方向键上下移动，BACK 关闭 |
| 时间轴标记 | 进度条上 2dp 粉线 + 6dp 三角标记片头/片尾位置 | 同左 |
| 自动跳过 | 片头：起播 seek 至记忆点 + 3s 轻提示「已跳过片头 · 01:25」；片尾：到点自动下一集 + 3s 提示「已跳过片尾」 | 同左；提示不参与焦点 |
| 详情页记忆行 | 高 44dp 玻璃行「本剧跳过：片头 01:25 · 片尾 02:10」+ 右侧「清除」36dp；无记忆时「未记忆 · 播放中长按进度条标记」 | 高 48dp、整行聚焦、「清除」44dp；首焦点不变（仍为主播放） |

### 1.2 状态

- **未标记**：详情页灰字提示；播放中浮层只显示「标记…」按钮。
- **已标记**：详情页显示时长 + 清除；清除弹确认「清除本剧的片头/片尾记忆？」，默认焦点「取消」。
- **未就绪**：播放器未准备完成时标记入口禁用并提示「加载完成后可标记」。
- **保存失败**：Toast「保存失败，请重试」，不关闭浮层；不产生半条数据。
- **直播**：不显示标记入口、不记忆。

### 1.3 边界与不做

- 记忆键 = `site.key + 规范化剧名（含季）`；同剧跨线路/跨集共享；历史续播优先于片头跳过；用户主动重播不跳过。
- 片头 0–180s、片尾 0–180s；超出/无效（片头+片尾≥时长）时忽略并提示。
- 不做：音频指纹/AI 自动识别片头片尾、跨设备同步、按单集独立记忆；本地最多 500 部（LRU），超出淘汰最旧。

## 2. #6 搜索跨源聚合去重

### 2.1 组件结构

| 组件 | 手机 | TV |
| --- | --- | --- |
| 合并卡 | 高 96dp 横卡：64×96 海报（2:3 圆角 12）+ 标题 15sp bold + meta 12sp + 来源徽标 10.5sp「3 个来源」+ 来源名 11sp；点卡进详情，长按弹「选择来源」底部浮层 | **单列大行**高 112dp：72×108 海报 + 标题 19sp bold + meta 13sp + 来源徽标 13sp；最大宽 760dp 左对齐；OK 进详情（自动优选可用线路） |
| 详情内切源 | 现有「⇄ 片源」改为「来源 · 3」胶囊，展开来源列表；切换后重载详情/线路，集名相同则保留集 | 详情页「来源」行 48dp（线路列表上方），左右切换、OK 应用 |
| 合并规则 | 标题规范化（去空格/标点/全半角）后同名；**年份或季不同不合并**；来源排序：当前源 → 上次播放成功源 → 配置顺序 | 同左 |
| 去重展示 | 合并卡不重复海报；来源徽标显示实际来源数；部分源失败时徽标旁加「1 失败」 | 同左 |

### 2.2 状态

- **加载**：顶部「正在搜索 N 个来源…」+ 22dp 粉环；结果按源返回增量插入，不整页闪。
- **空结果**：17sp「没有找到「关键词」」+ 13sp「换个片名/别名，或检查来源配置」。
- **部分失败**：结果保留 + 顶部 13sp 橙条「2 个来源失败 · 重试」（只重试失败源）；卡片仍可用。
- **全部失败**：17sp「搜索失败」+ 13sp 原因 + 48dp「重试」；不自动重试。
- **源内验证/需登录**：卡片标灰 + 「需在来源登录」，点击进来源登录引导。

### 2.3 边界与不做

- 不做跨源合并剧集/播放地址；不预加载所有源详情（避免请求爆炸）；不引入云端搜索；不改源插件 UI。
- 合并结果不跨会话缓存；同一关键词再次搜索重新聚合；最多展示 120 条合并结果。
- 优选线路失败时回退第一个有剧集的线路并 Toast「已切换可用线路」。

## 3. #7 片库批量整理 + 收藏分组 + 本地搜索

### 3.1 组件结构

| 组件 | 手机 | TV |
| --- | --- | --- |
| 页头 | 「片库」22sp + 页签 44dp + 右侧「搜索」44dp + 「管理」13sp | 标题 24sp + 页签 44dp + 「搜索」44dp（OK 打开字母键盘） |
| 本地搜索 | 页签下 40dp 玻璃输入框，占位「搜索片名 / 来源」；右侧 × 清空；过滤当前页签，200ms 防抖 | 搜索行 48dp，OK 打开遥控字母键盘（复用现有 PinyinKeyboardModel）；输入后实时过滤，BACK 关闭键盘再清空 |
| 多选态 | 长按行/卡 500ms 进入；勾选圆 22dp（选中粉底白勾）；页头变「已选 N 项」+ 全选 / 删除（历史）或取消收藏（收藏）/ 移动分组 / 退出；底部操作栏 56dp | 长按 OK 1.2s 进入；勾选 24dp；操作栏 48dp；首焦点为当前项，动作栏在列表末尾下方 |
| 收藏分组 | 「我的收藏」页签下 34dp（热区 44）胶囊行：全部 / 默认 / 自定义组… + 「管理分组」；长按组可重命名 | 页签下 44dp 胶囊行，左右切换、OK 应用；「管理分组」44dp |
| 分组管理 | 玻璃弹层宽 360：组名 + 数量 + 重命名/删除；「新建分组」44dp；输入 1–8 字 | 宽 560：左右/上下移动；新建/重命名用遥控字母键盘；删除组确认「组内收藏将回到默认，不会删除收藏」 |
| 批量动作 | 历史：删除所选（确认「删除所选 N 条观看记录？」）；收藏：取消收藏（确认）/ 移动分组（选择组）；默认焦点「取消」 | 同左；执行后退出多选并 Toast「已删除 N 条 / 已取消收藏 N 项 / 已移动到「组名」」 |

### 3.2 状态

- **空**：沿用现有空态（64dp 图标 + 17sp + 13sp + 按钮）；搜索无结果「没有匹配的收藏/历史」+「清除搜索」；分组为空「该分组还没有影片」。
- **加载**：历史/收藏本地读取，无网络 loading；列表 >200 条时分批渲染（首屏 50）；下载页沿用现有加载态。
- **失败**：打开条目时来源不可用 → Toast「该收藏的片源不可用」；写 prefs 失败 → Toast「保存失败，请重试」，列表不丢数据。
- **多选 0 项**：操作按钮置灰，不弹确认。

### 3.3 手机 / TV 差异与边界

- 手机：触屏点选/长按、搜索框直接输入；勾选与操作栏底部固定；长按时长震动反馈。
- TV：无触屏小按钮；长按 OK 进多选；勾选圆与操作栏均 ≥48dp；搜索/分组名用遥控字母键盘；BACK 顺序＝退出键盘/弹层 → 退出多选 → 返回上一页。
- 边界：切换页签/搜索词时清空选择；「全选」只选当前过滤结果；分组删除不删收藏；不做嵌套分组、云端同步、批量下载。
- 待确认：TV 新建/重命名分组用遥控键盘（推荐）还是提示「请在手机端管理」；收藏分组上限（建议 20 组）；搜索是否覆盖「我的下载」（建议仅历史/收藏）。
