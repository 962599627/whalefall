# 「鲸落」电视台直播 · UI 视觉重构说明

> 范围：`android/src/main/java/com/whalefall/movie/TvLive.java`（页面 + 播放器外层 chrome）与新增的
> `TvUiKit.java`。不改 XML、不加依赖、不动 AndroidManifest，纯代码 View / Canvas。
>
> 设计方向来自 WebViewTvLive 参考例图：**左分类栏（带数量）+ 中间编号频道列表 + 右侧频道信息**，
> 播放页是「视频铺满 + 悬浮 chrome」。视觉语言继续用鲸落现有的深海蓝 / 蓝白玻璃 / 樱花粉。

---

## 1. 视觉基调（沿用 Skin）

| 语义 | 取值 | 用途 |
| --- | --- | --- |
| 深海蓝底 | `#0B1220` / 渐变 `#0E1B31 → #0B1220 → #070D18` | 页面背景（`Skin.backdrop`，带右上樱花粉光晕） |
| 玻璃面 | 白 10%–25% 填充 + `#2EFFFFFF` 描边 | 分类栏、列表卡、右侧面板、播放器 chrome |
| 主文字 | `#F5F7FC` | 标题、频道名 |
| 次文字 | `#A9B7D0` / `#8D9CB6` / `#6F7F99` | 说明、数量、提示 |
| 樱花粉强调 | `#FF8FB1` / `#FFB3C8` / 渐变 `#FFC7D6 → #F59AB5` | 选中态、直播圆点、收藏、主按钮 |
| 台标品牌色 | CCTV 深红 `#C62B31 → #7C1219`；卫视各自主色 | 台标色块（只借用品牌色做识别，不改变页面主色） |
| 分裂线 | `#1AFFFFFF` / `#12FFFFFF` | 分类栏底部分割、列表行微分割 |

- 圆角：胶囊 999dp；分类选中块 14dp；列表选中行 14dp；卡片 18–24dp；台标块 7–18dp。
- 描边：统一 0.7–1dp，半透明白，避免「塑料块」。
- 阴影：仅主按钮与播放器顶栏用 `elevation`（2–8dp），保持克制。
- 不用纯黑：播放器视频底用 `#05070C`（比纯黑偏蓝），chrome 用 `#0B1220` 半透玻璃。

## 2. 页面信息架构

### 平板横向（窗口 ≥ 720dp 且非竖屏，即 1300×867 / 866dp 真机）

```
┌ 吸顶头部 ─────────────────────────────────────────────┐
│ 电视台直播   ● 直播中                                  │
│ 27 个频道 · 央视 19 · 卫视 8 · 官方网页直播，数字键…   │
│ ┌ 搜索频道或拼音首字母，如 hnws、cctv5 ─────────────┐  │
└───────────────────────────────────────────────────────┘
┌ 分类栏 150dp ┐ ┌ 编号列表（自适应） ──────┐ ┌ 信息面板 252dp ─┐
│ 频道分类     │ │ 央视频道     19 个   长按收藏│ │ [ 台标大色块 ]  │
│ ▌央视频道 19 │ │ 01 [块] CCTV-1 综合  ♡   │ │ CCTV-1 综合    │
│  卫视频道 8  │ │ 02 [块] CCTV-2 财经  ♡   │ │ 央视频道 · 直播 │
│  我的收藏 0  │ │ 03 [块] CCTV-3 综艺  ♡   │ │ 官方网页直播…   │
│ …            │ │ …（滚动）                │ │ ♡ 收藏频道      │
│ ───────────  │ │                          │ │ ▶ 观看直播      │
│ ＋ 添加频道   │ │                          │ │                 │
│ 导入频道列表  │ │                          │ │                 │
└──────────────┘ └──────────────────────────┘ └─────────────────┘
```

- **分类栏**：分组名 + 数量（央视 / 卫视 / 收藏）；选中项樱花粉渐变块 + 深色文字，未选中玻璃块；
  底部放「＋ 添加频道 / 导入频道列表」，把低频操作从头部移走，头部只留标题与搜索。
- **编号列表**：`序号 + 台标色块 + 频道名 + 直播中标签 + 收藏心形`；当前频道整行粉玻璃高亮、
  序号与名称变粉、右侧出现「● 直播中」小胶囊。行高 54dp，字号 16sp，长按收藏、点心形也收藏。
- **右侧信息面板**：用台标大色块代替视频预览（官方流在 WebView 里，列表页不额外开解码器），
  显示频道名、分类、观看提示、列表编号，底部固定「♡ 收藏频道」+「▶ 观看直播」两枚按钮。
  列表为空时面板退化为空状态（与中间列表同文案、同主按钮）。

### 手机竖屏（窗口 < 720dp 或竖屏，含窄平板）

- 顶部：标题 + `＋ 自定义` / `导入列表` → 直播状态副标题 → 搜索框（全宽）。
- 其下：**横向滚动分类胶囊**（带数量，选中粉渐变）→ **单列编号列表**（行高 58dp、名称 15sp）。
- 底部预留 96dp，避免被悬浮 Dock 盖住；列表可一直滚到底。

## 3. 搜索与状态

- 输入即过滤（`TextWatcher`），命中规则：频道名包含、去分隔符全名（`cctv1` 命中 `CCTV-1`）、
  拼音首字母（`hnws`、`cctv5`、`tyss`、`zwgj`…）。结果跨全部分组，左侧分组栏取消高亮。
- 搜索时中间标题变「搜索结果」；清空按钮 `×` 在输入非空时出现；`× 清空搜索` 副入口在标题右侧。
- **空状态**（收藏为空 / 搜索无结果）：64dp 圆形粉玻璃徽标（星形或 Canvas 放大镜）+ 标题 +
  两行说明 + 樱花粉胶囊按钮（「去央视频道看看」/「清空搜索」），不做干巴巴一行字。
- **加载态**：列表页数据本地同步生成，无网络加载；加载态集中在播放器（见下）。

## 4. 播放器 chrome（全屏 WebView 之上）

- 层级：WebView 全屏 → 居中加载卡 → chrome 容器（顶栏 + 右侧信息面板 + 底部频道条）。
- **顶栏**（玻璃 `#0B1220` 45% + 白描边，圆角 20dp）：返回圆钮、34dp 台标块、台名 + 「● 直播中 ·
  官方网页直播」、右侧 `频道 / 刷新 / 全屏` 三枚玻璃胶囊。
  - 刷新 → 重新 `load()`；全屏 → 保留原逻辑发送 F 键给网页播放器；频道 → 展开底部频道条。
- **右侧信息面板**（172dp，宽屏才显示）：视频源 `1 / 2 / 3`、画面比例 `16:9 / 4:3`、画面尺寸
  （真实取 `WebView` 像素尺寸，随布局变化刷新）、收藏频道、当前时间。1 号源与 16:9 为樱花粉高亮。
- **底部频道条**（默认收起）：分组胶囊（央视 / 卫视 / 收藏）+「数字键 1–9 换台」提示 + 收起按钮；
  第二行横向频道胶囊（22dp 台标 + 台名），当前台粉渐变；选台后自动收起。
- **加载卡**：居中玻璃卡（约 240dp），樱花粉 Canvas 转圈 + 「正在连接 CCTV-1 综合」+
  「正在加载官方页面 42%」；`onPageStarted` 显示、`onPageFinished` 淡出。
- **自动淡出**：任何 chrome 操作重置 3 秒计时；计时结束整体 260ms 淡出为 `INVISIBLE`；
  点击视频区域（WebView 轻点检测，滑动不触发）唤出 / 收起；换台、切分组、展开面板都会唤出并重置计时。
- 保留全部原有能力：数字键换台、返回关闭 / 网页回退、上下滑左亮度右音量、自动注入 JS + F 键全屏、
  `onShowCustomView` 网页全屏时顶栏隐藏。

## 6. 自评

加分的点：

1. 信息层级从「等宽卡片墙」变成「分类 → 编号列表 → 详情」的电视 App 结构，视线从左到右、
   从上到下都有明确落点，当前台一眼可辨（粉玻璃 + 序号 + 直播中）。
2. 台标色块让 CCTV / 卫视有了品牌识别，同时没有破坏深海蓝主色；右上角信息面板把「直播中」的
   即时感做出来了。
3. 播放器 chrome 是真正的「悬浮层」：玻璃条 + 3 秒淡出 + 点按唤出 + 可收起频道条，
   不再像旧版那样一条黑条压在网页上。
4. 空状态、加载态、收藏反馈都有专门设计，不是一行灰字。
5. 全部用现有 API / 现有主题常量，无新依赖、无 XML，手机与平板共用一套行/块构造器，行为一致。

## 7. 已知不足 / 下一步

- **无 EPG**：官方页没有节目单接口，列表只显示「直播中」，没有「正在播出：XXX」。如果以后能拿到
  央视节目单，右侧面板留了位置放。
- **右侧不是真视频预览**：列表页没有额外 WebView 解码，用台标大色块代替；若要真预览需要再开一个
  静音 WebView，代价较大，暂不做。
- **视频源 2/3、4:3 是占位交互**：目前只有 1 个官方源，点 2/3 会 toast 说明「暂无备用官方源」，
  不去伪造切换；4:3 同理由网页播放器控制。后续接入多源后再改成真切换。
- **「全屏」按钮**仍是向网页发 F 键（与原自动全屏逻辑一致），不是切换系统沉浸模式；若用户期望
  进入系统级全屏，可改调 `togglePlayerOrientation()`，待确认。
- **平板密度差异**：三段式阈值 720dp。若设备密度使窗口 < 720dp 会退化为手机单列布局（仍是
  分类胶囊 + 单列列表，可用但不如图示三段式完整）。
- **无法本地编译/截图**：本会话 bash 被限制，Java 语法与布局效果需要 Lead 编译 + 真机截图后确认，
  预计 2 轮内修正间距 / 字号 / 台标色。

## 8. 第二轮微调（真机 1300×867 / 密度≈1.3 反馈后）

真机首屏反馈：方向正确；列表行高偏大（一屏 8 行）、右侧台标块内部太空、分类栏底部按钮贴底且字小、
标题与直播胶囊纵向对齐略松、播放器信息面板需要滑入动效。对应调整：

| 项 | 第一版 | 第二版 |

| 行内间距 | 左 8 / 编号 34 / 台标 28 / 名称间距 11 | 左 6 / 编号 30 / 台标 26 / 名称间距 9 |
| 行字号 | 名称 16sp / 序号 14sp | 名称 15.5sp / 序号 13.5sp |
| 列表头部 | 上 12 / 下 8 | 上 9 / 下 6 |
| 右侧台标卡 | 竖排「CCTV / 1」两行小字 | **横排台标**：`CCTV | 1`（卫视 `湖南 卫视`），字号 21/34sp，右上角直播胶囊加大 |
| 面板中段 | 编号一行 + 大片留白 | 加「分类 / 编号 / 播放」三行信息，留白变成结构 |
