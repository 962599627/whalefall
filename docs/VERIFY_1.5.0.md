## V39 夸克原生登录与真实数据（P1，E8 Phase1，约 5 分钟）

1. 进「网盘与账号」：用 **App 内 WebView 完成夸克登录**（扫码/账号密码）。
2. 登录后应显示**真实账号名与容量**（来自官方接口，非本地缓存/写死）→ 截图 `mobile-V39-1.png`。
3. 应能列出**真实网盘文件列表**（文件名/大小/时间，与官方 App/网页一致），可进目录、可返回 → 截图 `mobile-V39-2.png`。
4. **退出登录**：状态与列表**立即清除**，回到未登录态。

- 通过标准：**账号名 / 容量 / 文件列表三项都来自真实 API 且可与官方对照**；手动标记、写死值、本地缓存均**不算**。
- 证据：`mobile-V39-1.png`（账号/容量）、`mobile-V39-2.png`（文件列表）；退出后可选 `mobile-V39-3.png`。
- **不通过**：显示「已登录」但没有真实账号名/容量 / 列表为空或假数据 / 退出后仍显示已登录 / 必须手动标记才显示状态。
- 边界：仅访问**用户自己授权**的账号；不内置/不共享/不代理他人资源；网盘接口变更属外部风险。

## 出证后回我一句

「1.5.0 V39：夸克登录后是否显示真实账号名/容量、文件列表是否与官方一致、退出后是否清除。」

---

**实测结果（2026-11-10 14:24，1.5.0 包）**：夸克 **App 内登录成功**，面板显示「已登录（夸克原生）」；但——

1. **退出登录 / 清除凭据后仍显示已登录**（状态没清除）；
2. **登录页把整个夸克网页显示出来**（用户要求**只显示二维码**）；
3. **「我的阿狸」误报「已登录（多条凭据）」**（未登录的盘被标成已登录）。

**结论：V39 未通过**，转 **1.5.1** 修这三项并保文件列表（见 `docs/VERIFY_1.5.1.md` **V40**）。
