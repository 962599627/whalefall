## 1. 近期反馈转验收标准

### A1 启动崩溃回归（P0）

- **功能描述**：覆盖安装、冷启动、后台被杀后重建、旧版本升级后启动均不闪退，数据保留。
- **交互期望**：连续冷启动 20 次 0 崩溃；1.9.x 旧包覆盖安装后正常启动且配置/历史/收藏保留；中端设备启动到可操作 ≤5s；若连续 2 次启动崩溃，第 3 次进入安全模式且「恢复默认」可达；崩溃有日志记录。
- **不通过示例**：任一冷启动闪退/白屏/卡启动页；升级后数据被清空；安全模式不触发或无法退出；崩溃日志为空。
- **优先级**：P0（可启动是底线，任何一条不过即阻塞发布）。

### A2 越看越卡（P1）

- **功能描述**：长时间播放、连续切台、连续切页后，操作与播放不随时间劣化。
- **交互期望**：连续播放 ≥60min + 切台/切页 ≥50 次后，呼出控制条/切台/返回的响应与第 1 分钟无明显差异；每 15min 采样 PSS 不单调增长（后段 ≤ 前段 120%），退出播放器后回落至进入前 +80MB 内；`UiAudit issues=[]`，无重复 overlay/重复加载；TV 直播 10min 无持续发热或明显掉帧。
- **不通过示例**：30min 内明显变慢/掉帧；PSS 持续上涨且退出不回落；切台越多次越慢；出现 ANR；直播页面叠出多层播放器/声音。
- **优先级**：P1（性能退化按严重体验问题处理；若实测 30min 内不可用，升 P0）。

### A3 筛选三层焦点（P1）

- **功能描述**：首页三层筛选（L1 分类行 → L2 筛选 chips → L3 选项行）在 TV 遥控/外接键鼠下的焦点导航与选中。
- **交互期望**：焦点框始终可见（2dp 内环 + 10% 粉底，不缩放、不外发光、不出界、不盖相邻卡片，按 `DESIGN_FOCUS_TV.md`）；层内左右移动、DOWN 进下一层、UP 回上层、OK 选中后收起回 L2 且焦点停在触发的 chip；BACK 逐层收（L3→L2→退出筛选/页面），不直接退出 App；选中后列表刷新且焦点不回跳；日志 `FilterLayer` / `FilterFocus` 正常、`TvFocusAudit missing=[]`。
- **不通过示例**：丢焦/焦点跑到屏外/被父容器裁切；DOWN 跳层或无法进入 L3；BACK 一下直接退出 App；选完焦点消失或回跳顶部；焦点缩放导致布局抖动。
- **优先级**：P1。

### A4 底部按钮 / 中央三键焦点框（P2，焦点完全不可见则升 P1）

- **功能描述**：播放页底部控制条按钮与中央三键（快退 / 播放暂停 / 快进）的焦点态。
- **交互期望**：进入播放页后遥控焦点可进入控制条；三键与底部按钮均可聚焦，焦点框可见且不越界（内环、不缩放、不改布局）；左右顺序与视觉排列一致，OK 触发，BACK 收起 chrome 或返回；chrome 隐藏时焦点不落在不可见控件；日志 `PlayerFocus`、`TvFocusAudit missing=[]`。
- **不通过示例**：三键/底部按钮无焦点框或被裁掉一半；焦点顺序错乱（底栏跳到顶栏）；焦点停在隐藏按钮；焦点框导致底栏抖动/遮挡进度条。
- **优先级**：P2（可视性/一致性）；若实测焦点完全不可见，按 P1 阻塞。

### A5 IPTV 选择体验（P1）

- **功能描述**：开源 IPTV 频道选择——列表分类筛选、播放页 OK 唤出频道选择器（左分类、右频道、当前高亮）、OK 切台。
- **交互期望**：播放页 OK 后 1s 内唤出选择器；切分类 ≤500ms 刷新；当前频道高亮可辨；OK 切台后旧流停止、新台起播（失败给出备用源/失败提示，不黑屏无提示）；BACK 关闭选择器回播放页、再 BACK 退出；焦点可见不漏；无频道时显示空态与「刷新」入口。
- **不通过示例**：OK 无反应/选择器超出屏幕/无法 BACK；切台后双声、黑屏或一直「正在加载」；焦点丢失；列表错位或串台；空列表无提示。
- **优先级**：P1。

### A6 壁纸偶发消失（P1）

- **功能描述**：静态/动态壁纸在页面切换、返回、旋转、播放进出、安全模式开关后不消失、不变成纯色。
- **交互期望**：连续 30 次「首页 → 详情 → 选集 → 返回 / 切 tab / 旋转」后壁纸仍在；动态壁纸持续播放；播放页为纯黑不铺壁纸、退出后恢复；同一时刻两页壁纸一致；关闭安全模式后壁纸恢复；异常后 1s 内可自恢复。
- **不通过示例**：任一次返回/切页后变纯色或壁纸消失；动态壁纸停止；播放页出现壁纸；两页壁纸不一致；安全模式关闭后不恢复。
- **优先级**：P1。

## 3. 本轮不做（范围排除）

1. **X5 网页直播暂不启用**：网页直播/网页播放一律走系统 WebView（X5 SDK 未集成），不承诺 X5 内核效果，不因 X5 阻塞发布。
2. **不改手机版布局/行为**（除本次 6 项验收所需）；**不做 TV 手势交互**；**不把手机 Dock 壳搬到 TV**。
3. 不做 Compose/Kotlin 重写、targetSdk 升级、实测 Baseline Profile、跨端同步。
4. 不做内置/托管直播源、直连 m3u8、第三方 IPTV 源扩展、EPG 节目单（合规与范围红线）。
5. 不做网盘原生直连（E8 已搁置）、不做新播放格式/新内容能力。
6. 不做「全机型 × API 23–35」完整矩阵，只做清单化抽检 + 用户真机补证。
