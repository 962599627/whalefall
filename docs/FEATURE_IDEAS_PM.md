# PM 视角新功能建议（3 条，2026-11-10，基线 1.7.10）

> 选取原则：优先用户可感知、复用现有数据、不与 DEV/QA/ARCH 建议重复；不含实现方案。

1. **TV 扫码填词（电视端搜索/输地址不再用遥控器逐字敲）**｜痛点：TV 搜索、改频道地址只能遥控挪格输入，长词几乎不可用；目标用户：TV/盒子用户。工作量：S。是否值得做：**是**——小投入解锁 TV 端高频入口，属媒体类 TV 端标配体验。
2. **片库批量整理 + 收藏分组**｜痛点：历史/收藏只增不减，只能逐条删、找片靠翻页；目标用户：重度追剧与长期用户。工作量：M。是否值得做：**是**——数据已存在，补齐整理能力即可显著降低找片成本。
3. **儿童/家长模式（内容分级 + 单次/每日观看时长上限）**｜痛点：家庭电视/平板场景无法限制孩子看什么、看多久；目标用户：家庭用户。工作量：M。是否值得做：**值得，但有前置**——先定分级口径与密码保护取舍，可随 TV 端试点。
