# TV / 手机被控端 · 焦点态视觉规范（1.9.38）

> 目标：解决遥控/键盘焦点「放大溢出、盖住相邻卡片、描边被父容器裁切」的问题；统一卡片、分类 chip、侧栏图标、设置条目、详情按钮、控制条按钮、弹层格子的焦点态。
> 范围：TV 遥控焦点 + 手机被控端同一套（手机外接键鼠/遥控同样适用）。只写规范，不碰代码。
> 原则：**焦点只做「内描边 + 轻微底色 + 内容色变化」；卡片不缩放、不位移、不发光、不 elevation。** 所有颜色只用现有 token。

## 0. 统一焦点 token

| 用途 | 值 |
| --- | --- |
| 焦点环（默认） | 2dp `ACCENT_SOFT #FFB3C8`，画在组件**内侧**，inset 1dp，圆角跟随组件 |
| 焦点环（组件底已是 ACCENT 实心） | 2dp `TEXT_PRIMARY #F5F7FC`（避免粉底上看不见） |
| 焦点底色 | `#1AFF8FB1`（10% ACCENT，叠在原底上） |
| 焦点文字/图标 | 未选：`TEXT_PRIMARY #F5F7FC`；已选：`ACCENT_SOFT #FFB3C8`；深色按钮保持 `BG_DEEP #070D18` |
| 强调条（卡片/设置行/弹层行） | 3dp `ACCENT #FF8FB1`，贴内侧，不超出边界 |
| 焦点动效 | 进 120ms、出 100ms，`DecelerateInterpolator`；不做 scale/弹性/外发光；Reduced 即时 |
| 禁止 | 外发光、阴影/elevation、scale>1.02、卡片缩放、描边出界、`unclipAncestors` 后盖住邻居 |

> 关键实现约束：焦点环必须是**内容层之上的 overlay/foreground**（poster 卡被图片盖住时尤其如此），不能用 `background` 的 stroke 代替；所有父容器保持 `clipChildren=true`，靠 inset 保证不裁。

## 1. 卡片（海报卡 / 历史卡 / 今晚卡）

| 项 | 值 |
| --- | --- |
| 缩放 | **1.0（不缩放、不平移）** |
| 焦点环 | 2dp `ACCENT_SOFT`，inset 1dp；圆角=卡片圆角（海报 12/14，历史 16） |
| 底部高亮 | 3dp `ACCENT`，左/右各 inset 8dp、底 inset 6dp，圆角 1.5dp；海报卡画在图片之上 |
| 底色 | 历史/今晚玻璃卡叠 `#1AFF8FB1`；海报卡只加环+底条，不改变海报 |
| 文字 | 卡内标题/角标不变；历史卡标题 `TEXT_PRIMARY`，进度条仍 `ACCENT` |
| 动效 | 环 alpha 0→1 + 底条 alpha 0→1，120ms Decelerate；移出 100ms |
| 父容器 | `clipChildren=true` 可保留；卡片间距 ≥12dp（手机）、≥16dp（TV）；不得再调用 `unclipAncestors` |
| 禁止 | `gain 1.02/1.035` 缩放、elevation、白色 2dp 外描边、相邻卡片被盖 |

验收：焦点移动时海报/历史卡尺寸不变，环与底条完整落在卡片内，相邻卡片的像素不被覆盖。

## 2. 分类 chip（L1）

| 项 | 未选中 | 焦点 |
| --- | --- | --- |
| 背景 | `#CC172842→#CC182B4C` 玻璃 | 原底 + `#1AFF8FB1` |
| 描边 | 1dp `#38FFFFFF` | 2dp `ACCENT_SOFT`（内侧，inset 1dp） |
| 文字 | 用户字体色（中性） | `TEXT_PRIMARY` |
| 圆角 | 999 | 999 |
| 缩放 | 1.0 | 1.0 |
| 已选中 chip | `ACCENT→ACCENT_SOFT` 渐变 + `BG_DEEP` 字 | 保持渐变；焦点环改 2dp `TEXT_PRIMARY` |

- 无漏斗时只聚焦底色；有漏斗时漏斗颜色不变（选中 `BG_DEEP`，未选中按 1.9.36 规则）。
- 动效 120ms；不放大、不位移。

验收：焦点在分类行左右移动时，chip 外轮廓不超出分类行高度，圆角完整，选中粉色不被白环破坏。

## 7. 弹层格子（AppDialog / 选源 / 选色）

| 项 | 值 |
| --- | --- |
| 行高/圆角 | ≥44dp，圆角 10dp |
| 未选 | 透明底；文字 `TEXT_PRIMARY` |
| 焦点 | 底 `#1AFF8FB1`；左侧 3dp `ACCENT` 竖条（上下 inset 5dp）；文字 `ACCENT_SOFT` |

验收：焦点格子的高亮与左条都落在弹层内，不越过弹层圆角，不盖相邻格子。

## 8. 动效曲线与状态

- 焦点进入：颜色/环 alpha/底条 alpha **120ms Decelerate**；焦点移出 **100ms Decelerate**。
- 不做 scale 弹性；`FocusMotion` 的 spring overshoot 不用于缩放（gain 必须 1.0）；颜色插值可保留。
- `Prefs.REDUCED`/系统性减少动画：直接切换，不淡入。
- 按下态（OK/触摸）可在焦点态上再叠 `#26FF8FB1`，持续 80ms，不改变尺寸。

## 9. 明确禁止

1. 外发光、shadow、elevation、blur 光晕。
2. 卡片缩放（任何 >1.0）；其他组件缩放 >1.02。
3. 2dp 以上描边画在组件外；描边出界被父 `clipChildren` 裁切。
4. 调 `unclipAncestors` 让焦点溢出到相邻卡片/行。
5. 用白色 2dp 粗描边包住整张海报卡（视觉过重）。
6. 焦点位移（translationX/Y）导致相邻卡片被盖。
7. 焦点态改变布局高度/宽度，造成列表抖动。

## 10. 验收清单（一句话版）

- 海报/历史卡：焦点尺寸不变，2dp 内环 + 3dp 底条完整在卡内，邻卡不被盖。
- 分类 chip：焦点只加 10% 粉底 + 2dp 粉环，不出分类行、不缩放。
- 侧栏图标：焦点环在 44/48dp 格内，图标变白，不盖相邻图标。
- 设置/弹层行：10% 粉底 + 3dp 左侧粉条，行高不变、不越界。
- 详情按钮：主按钮白环、次按钮粉环，均内嵌、不互盖。
- 控制条：焦点按钮不压进度条、不出控制条。
- 全端统一：TV 与手机被控端同一套色值/尺寸/时长；无新色、无外发光、无缩放溢出。
