## V28 播放页不被壁纸遮挡（P1，DEF-2024，约 6 分钟）

**动态壁纸一遍**（设动态壁纸后）：

1. 进任一集播放（如 Dreamland 第01集）：**只见视频、播放页纯黑**，不能看到壁纸动画。
2. 退出播放：列表/首页的壁纸**恢复**（不丢、不变纯色）。
3. 旋转一次（竖→横）再进/出播放一次，重复 1–2。

**静态壁纸一遍**：换成静态壁纸，重复 1–3。

- 期望：播放中无壁纸层、视频不被遮；退出后壁纸恢复；旋转不复发。
- 证据：`mobile-V28-1.mp4`（动态壁纸，30s）、`mobile-V28-2.mp4`（静态壁纸，20s）。
- **不通过**：播放页仍看到壁纸 / 视频被遮 / 退出后壁纸不恢复 / 旋转后复发。

## V29 更新包体选择（P2，DEF-2025，约 5 分钟）

1. 设置 → 检查更新 → 手动检查：应出现**可选包体列表**（标准 / arm64 / R8 / TV，按 feed 与设备形态）。
2. 选中 **arm64 或 R8** → 下载：完成后的**文件大小与 sha256** 应与所选变体一致（下载页/文件信息可核对）。
3. **TV 端**检查更新：只应列 **tv 包**，不出现手机包。
4. **旧 feed（无 `variants`）**：行为与之前一致（单包直接下载），不报错。

- 期望：包体列表可选择；下载按所选包校验；TV 只列 tv；旧 feed 兼容。
- 证据：`mobile-V29-1.png`（包体列表）、`mobile-V29-2.png`（下载完成/文件信息）；TV 若可测加 `TV-V29-1.png`。
- **不通过**：无包体列表 / 选了却下错文件或大小/sha 不符 / TV 出现非 tv 包 / 旧 feed 行为变化。
- 若改 feed/断网不方便：至少完成第 1–2 步（手机列表 + 选中下载正确文件），第 3–4 步标注「**未真机验证**」，由 Lead/QA 静态核对兼容逻辑。

## V30 字体颜色自定义（P2，DEF-2026，约 5 分钟）

**手机**：设置 → **界面外观 → 字体颜色**：

1. 弹窗应出现 **9 格色板 + 推荐组合 + RGB 滑条**（手机可输入 **HEX**）。
2. 选「**亮壁纸深灰**」或「樱粉」：预览与全局主要文字（首页 / 详情 / 设置）**立即变化**。
3. 点「**恢复默认**」→ 回到**月白**。
4. 保存后 `recreate()` 生效（退出重进仍生效）；再做一次**备份导出 → 恢复**，颜色应**仍生效**。

**TV**：设置 → **首页与壁纸 → 字体颜色**：遥控选色块、**±5** 调 RGB、**无 HEX**、按 **BACK 取消不保存**。

- 期望：主文字按所选色；次要文字同色降透明度；**樱花粉强调色不变**；可恢复默认；重启/备份恢复后保留。
- 证据：`mobile-V30-1.mp4`（或 `mobile-V30-1.png` 弹窗 + 全局效果）、`TV-V30-1.png`。
- **不通过**：选色不生效 / 预览与全局不一致 / 强调色被改 / 恢复默认无效 / 重启或备份恢复后丢失 / TV 出现 HEX 或 BACK 仍保存。
- 边界：**覆盖范围以交付说明为准**；直接 `setTextColor` 写死的文字不在覆盖内，**不作为失败项**。
