# 三层筛选 · 紧凑版视觉规格（1.9.35，取代 1.9.34）

> 背景：1.9.34 面板高度占屏大、L3 两行大网格像大胶囊、标题/标签被全局字体色染绿、留白过多。本稿目标：**低高度、少胶囊、粉色只出现在选中态、面板更薄**。
> 覆盖文件：`docs/DESIGN_FILTER_1.9.34.md`（此后以本稿为准）；实现：`MobileShell`（手机/平板）、`HomeScreen`（TV）。只写规格，不碰代码。

## 0. 结构（文字版）

```
页面内容
├ 分类行 CategoryRow（只保留分类胶囊 + 漏斗，无旧「筛选」按钮）
└ FilterPanel（inline；分类行下 6/8dp；圆角 16；无阴影）
   └ Column（padding：手机 10/6，平板 12/8，TV 14/10）
      ├ L2Row 34/36/40dp：类型、地区、年份 + 右侧「清除」
      └ L3Row（GONE）：单行 HorizontalScrollView，32/34dp 选项
```
- **删掉独立 header**：不再有「筛选 / 清除全部」两行结构，L2 行右侧只放一个小号「清除」文字（仅有已选值时出现）。面板闭合高度手机约 46dp、打开约 92dp（不再占大块）。
- 面板是 inline item：展开时 height 动画把下方内容下推，不覆盖卡片、不加阴影、不做全屏遮罩。

## 1. 精确尺寸

| 项 | 手机 | 平板 | TV |
| --- | --- | --- | --- |
| 面板左右外边距 | 16 | 24 | 24 |
| 面板上/下外边距 | 6 / 10 | 6 / 10 | 8 / 12 |
| 面板内边距 | 10 左右 / 6 上下 | 12 / 8 | 14 / 10 |
| 面板圆角/底色 | 16dp / `GLASS_FILL #1AFFFFFF` | 16 / 同 | 16 / 同 |
| 面板描边 | 1dp `STROKE_SOFT #1AFFFFFF` | 同 | 同（可 `#26FFFFFF`） |
| L2 行高 | **34dp** | **36dp** | **40dp** |
| L2 文字 | 12sp | 12sp | 14sp |
| L2 标签间距 | 12dp | 14dp | 16dp |
| L3 行高 | **40dp**（chip 32 + 上下 4） | 42dp（chip 32） | 46dp（chip 34） |
| L3 chip 高 | **32dp** | **32dp** | **34dp** |
| L3 chip 内边距 | 左右 **10dp** | 10dp | 12dp |
| L3 chip 间距 | **8dp** | 8dp | 10dp |
| 「清除」 | 11sp `TEXT_TERTIARY` | 11sp | 13sp |
| 面板椭圆高度 | 闭合 ≈46 / 打开 ≈92 | ≈52 / ≈100 | ≈58 / ≈110 |

- L3 **不做两行网格**：所有端均为**单行横滚**（手机/平板手指滑，TV 遥控左右）；chip 按内容宽，不 `weight`、不拉满、不等分。TV 如果后期必须换行，最多 2 行、行高 40、间距 8，不能回到 48/56 大胶囊。
- 分类行与面板间距 6dp（手机）/8dp（TV）；面板下方与状态/网格间距 10/12dp。

## 2. 颜色（粉色只给选中）

| 元素 | 未选 | 选中/展开 |
| --- | --- | --- |
| L2 类型/地区/年份 | 无底色；文字 `TEXT_SECONDARY #A9B7D0`；无边框 | **无底色**；文字 `ACCENT_SOFT #FFB3C8` bold；底部 2dp `ACCENT #FF8FB1` 下划线（宽 16/20dp，距字 4dp） |
| L2「清除」 | `TEXT_TERTIARY #8D9CB6` | 同色，点击即清空并收起面板 |
| L3 chip | 底 `#14FFFFFF` + 1dp `#1AFFFFFF` 描边；字 `TEXT_PRIMARY #F5F7FC` | 底 `ACCENT #FF8FB1` + 1dp `#66FFB3C8` 描边；字 `BG_DEEP #070D18` bold |
| 面板文字 | 不使用全局字体色/默认绿：显式 `TEXT_SECONDARY`/`TEXT_PRIMARY`；标题也不再单独出现 | — |

- **禁止**：面板标题/标签使用 `#4CFF80` 或其他用户字体色；粉色整块胶囊平铺；深色大底块；整行实心粉。
- 面板底色用 `GLASS_FILL`（半透明白玻璃）而不是 `#E6141C2A` 近不透明深蓝，避免「一块深色板」。

## 3. 交互（保持 1.9.34 循环）

| 状态 | 操作 | 结果 |
| --- | --- | --- |
| 分类未选中 | 点带漏斗分类 | 切换分类 → 展开 L2（46/58dp） |
| 分类已选中、无 L3 | 再点同一分类 | 展开「类型」L3（+40/46dp） |
| L3 展开 | 再点同一分类 | 收起面板到分类行 |
| L2 展开 | 点某标签 | 展开该维度 L3；只保留一个维度 |
| L3 展开 | 点选项 | 应用、收起 L3、L2 显示「类型 · 动作」，焦点回该标签 |
| L3 展开 | 点已选非「全部」 | 取消该维度，回到全部 |
| 任意层 | BACK | L3 → L2 → 正常返回 |
| 有筛选 | 点「清除」 | 清空全部、收起面板、焦点回分类 chip |

- 切换分类：清空筛选、按新分类加载、展开 L2。
- 全部与已选：`全部` 固定第一；点「全部」清除该维度。
- TV 焦点：L2 左右移动 → OK 展开 L3 → L3 左右移动 → OK 应用 → 焦点回该 L2；BACK 逐层；首焦点进 L2 第一项。

## 4. 动效

- 面板展开：height `0→目标` **140ms** ease-out + `alpha 0→1` + `translationY -4dp→0`；闭合 **120ms** 反向；L2→L3 高度增加 **120ms**。
- 选项选中颜色 100ms；apply 不重播面板/L2 入场。
- 禁止 `scaleY`；`Prefs.REDUCED` 瞬时；不加 elevation/阴影、不做 blur 遮罩。

## 5. 与 1.9.34 的差异（dev 重点）

1. 删除独立 header（「筛选 + 清除全部」），改为 L2 行右侧 11sp「清除」。
2. 删除 L3 换行网格；所有端改单行横滚，chip 高 32/34、padding 10/12、间距 8/10。
3. L2 从胶囊改为**文字标签 + 2dp 粉色下划线**，未选无底色；只有选中态出现粉。
4. 面板底从 `#E6141C2A`（近不透明）改为 `GLASS_FILL #1AFFFFFF`（薄玻璃），降低大块深色感。
5. 面板垂直留白减半：padding 10/6（手机）、12/8（平板）、14/10（TV）；行高 34/40，不再用 56dp 选项。
6. 标题/标签不跟随全局字体色（避免默认绿字），显式用 `TEXT_SECONDARY`；只有选中值用 `ACCENT_SOFT`。

## 6. 不做 / 待确认

- 不做：两行大网格、整行等分 chip、header 大标题、阴影、磨砂遮罩、面板高度超过 120dp（手机）。
- 待确认：TV 若单行横滚选项过多导致遥控移动过长，允许 2 行、每行 6、行高 40；默认按单行横滚交付。
- 待确认：L2 触控热区 34dp 低于 48dp 规范，属紧凑版取舍；如需无障碍，可在行高外增加透明热区，但不改变视觉高度。
