# 三层筛选 · 视觉重构规范（1.9.34）

> 目标：把 1.9.33 的「挤在一起的胶囊行」改成友商式**分类行下方浮出的筛选面板**：面板有玻璃卡片层次、L2 紧凑标签、L3 按内容宽度的选项、展开时内容平滑下移。
> 依据：`docs/WHALEFALL_DESIGN_SYSTEM.md`、`docs/LIBRARY_LAYOUT_SPEC.md`；代码：`MobileShell`（手机）、`HomeScreen`（TV）、`VideoFilters`。本轮只写规范，不碰代码。
> 修复对象：选项被 `weight=1` 拉成整行大块（`MobileShell:2174` / `HomeScreen:902-906`）、分类行残留旧「筛选」按钮（`MobileShell:1325-1338`）、L2 文案「国家 / 地区」（`VideoFilters.LABELS:9`）、展开后内容被压（L2/L3 直接塞进 body、无面板容器）。

---

## 0. 组件结构（文字版）

```
页面 ScrollView（首页/片库内容）
├ 品牌行
├ 历史记录
├ 今晚看什么
├ 分类行 CategoryRow（只放分类胶囊；右侧旧「筛选」按钮删除）
├ 筛选面板 FilterPanel（默认 GONE；分类行下 8dp，inline 占位）
│   ├ PanelPadding（14/12；TV 16/14）
│   ├ PanelHeader 24dp：「筛选」12sp TERTIARY + 右侧「清除全部」12sp ACCENT_SOFT
│   ├ L2Row 44/48dp：[类型] [地区] [年份]（胶囊，内容宽）
│   └ L3Area（默认 GONE；展开时显示）
│       ├ 手机：HorizontalScrollView 单行，左右 16dp，chip 内容宽
│       └ 平板/TV：换行网格，每行最多 8 / 6 个，行高 48/56，超出 3 行时 L3 内纵滚
├ 状态文案/网格（面板展开时整体下移，不覆盖）
└ …
```
- 谁包谁：`FilterPanel` 是 `body` 里的独立 item，位于分类行之后、状态文案之前；L2/L3 不直接加到 body。面板展开时把下方内容推下去（inline height 动画），不是浮层遮住卡片。
- 分类行的旧「筛选」按钮：删除视图与 `filterSize` 边距，不再占位；筛选入口只保留分类 chip 后缀漏斗。

| 项 | 手机 | 平板/TV |
| --- | --- | --- |
| 容器 | `HorizontalScrollView` 单行，左右 16dp，`clipToPadding=false`；切边 8dp 渐隐 | 换行网格：`LinearLayout` 行容器，每行最多 **8 / 6** 个，行距 8/10 |
| 行高 | 44dp | 48 / 56dp |
| chip 高 | **34dp**（热区 44） | **40dp**（热区 48） |
| 内边距 | 左右 12dp | 左右 16dp |
| 字号 | **12sp** | **14sp** |
| 圆角 | 999 | 999 |
| 间距 | 8dp | 8 / 10dp |
| 宽度 | **内容宽 + 统一 padding；禁止 `weight`/等分/拉满整行** | 同左；行内左对齐，末尾留白 |
| 未选 | 底 `#14FFFFFF`、描边 1dp `#1AFFFFFF`、字 `TEXT_PRIMARY #F5F7FC` | 同左 |
| 选中 | **实心 `ACCENT #FF8FB1`、深字 `BG_DEEP #070D18` bold、1dp `#66FFB3C8` 描边** | 同左 |
| 选项顺序 | 「全部」固定第一；后接源定义顺序 | 同左 |
| 交互 | 点选立即生效、L3 收起、L2 当前值更新；再点已选项取消回「全部」 | 同左；TV OK 选中后焦点回该 L2 标签 |
| 溢出 | 横滚，不换行 | 每行 8/6 个自动换行；超过 3 行时 L3 固定 3 行高、内部纵滚 |

- TV 选项区没有横滚：靠换行 + 上下行移动；左右在行内移动，行尾停住；焦点态 2dp 白描边。
- 手机不要用两行换行（会压缩内容高度），统一横滚。
- 选中粉底是 L3 唯一高饱和使用点；L2 保持 15% 低饱和，避免「一排粉胶囊」。

## 4. 动效与高度过渡

- **面板首次展开**（分类 chip 第一次点击）：面板从 `height=0` 动画到内容高，**180ms ease-out**；同时 `alpha 0→1`、`translationY -8dp→0`；下方内容随高度连续下移，不覆盖卡片。
- **L3 展开**（第二次点 L2 标签）：L3 区域高度 `0→目标高度`，**160ms ease-out**；面板总高同步增长；L2 标签底色/文字 120ms 过渡。
- **收起**：L3 先收 140ms → 面板收 160ms；反向淡出 + 上移 8dp；收起后焦点回分类 chip。
- **应用选项**：不重播面板/L2 入场动画；仅 L2 当前值文字与选中底色 120ms 变化，L3 立刻收起（或 140ms），焦点回该 L2 标签。
- `Prefs.REDUCED` 或系统减少动画：全部瞬时，不做高度/透明度动画。
- 禁止用 `scaleY` 压缩面板（会把 chip 文字压扁）；只允许 `height`/`alpha`/`translationY`。

## 5. 分类行（L1）与旧元素清理

- 分类行只保留分类胶囊：漏斗 14dp（TV 16dp）、间距 6/8；选中 chip `ACCENT→ACCENT_SOFT` 渐变 + `BG_DEEP` 字；未选玻璃 + `TEXT_PRIMARY`。
- 漏斗颜色：选中 chip 用 `BG_DEEP #070D18`；未选中「有筛选 ACCENT / 无筛选 `TEXT_TERTIARY`」；有筛选时仅在当前分类亮，不加独立粉点。
- **删除旧「筛选」按钮视图**（`MobileShell:1325-1338` 的 `filterButton` 与 `filterSize` 右 16dp 边距）；分类行右侧不再留 8+16dp 空位。
- 分类行与面板之间只留 8dp；分类行底部 padding 从 8dp 改为 4dp，避免双倍空隙。

## 7. 边界与不做

- 不做：浮层遮住内容、毛玻璃全屏 blur、彩虹渐变、每层独立滚动、L2 实心粉底、选项等分拉满。
- 源无筛选定义：分类 chip 不显示漏斗，点分类只切分类，不展开面板。
- 面板高度：手机不限（由页面滚动承载）；TV L3 最多 3 行后内部滚动，避免面板占满 540 屏。
- 兼容：保留 `VideoFilters` 维度/值/多选能力不变，只改展示层与别名（国家 / 地区 → 地区）；已选值仍走原过滤逻辑。
- 待确认 1：面板是否需要「阴影」而非仅描边；设计系统仅允许浮层阴影，本规范按**无大阴影 + 描边**处理。
- 待确认 2：TV L3「全部」是否单独固定在最左一列（建议随选项流，固定首项）。
