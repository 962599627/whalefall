## 本版内容

### 修复（1.3.x 用户实测问题）
1. **直播加载浮层不消失**（DEF-2010）：三条出口（真实播放探针 / 进度 100 / 网页全屏）+ inject 单例化。
2. **电视 tab 顶部按钮被裁切**（DEF-2011）：标题行与操作行分离。
3. **点频道后布局错乱/播放器不出现**（DEF-2012）：播放中旋转只 relayout 不整页重建；退出先摘播放器再恢复竖屏；手机竖屏不出侧栏。
4. **电视 tab 操作行对齐全靠左**（DEF-2014，按用户要求）。
5. **横屏右侧信息面板「收藏频道」被裁一半**（DEF-2015）：面板可滚动 + 导航条 inset。
6. **切 tab 回电视页变宽屏三栏 + Dock 压内容**（DEF-2016）：`onConfigurationChanged` 等真实布局完成再更新尺寸，手机竖屏强制单列。
7. **R8 包启动闪退**（DEF-2013）：恢复 kotlin-stdlib 依赖 + 锁定 AGP 8.7.3 重构。

### 新增（TV 版功能对齐，用户拍板 4 项）
- TV HomeDock 新增第 7 项「电视」→ 电视台直播（官方网页直播 + 频道管理入口；TV 频道管理本轮隐藏，登记未覆盖）。
- TV 设置新增「本机与工具」：文件管理（浏览/预览/删除，键鼠类操作降级提示）、管理员后台（只读 QR/地址/令牌/FTP）、崩溃日志（整页 + 另存到文件管理）、存储清理、观影统计、遥控器说明、关于。
- 抽取共享页 `ExtraPages.java`，手机版行为零变化（架构复核 M4 修复后确认）。

### 其它
- 首页网格 RecyclerView 虚拟化（E3-S1，1.3.0 起）；陕西卫视官方直播页；设置页版本号运行时读取。
