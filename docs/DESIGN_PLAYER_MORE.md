# 播放器右上角「更多」按钮 · 视觉规范（1.9.38）

> 范围：全屏播放器右上角「更多工具」三点按钮。目标：从 48dp 半透明圆 + 旧图标改为与中央三键同一玻璃胶囊语言，三点清晰、不笨重；TV/手机被控端同一套焦点。
> 只写规格，不碰代码。颜色只用现有 token：`PLAYER_CHIP #99000000`、`STROKE_SOFT #1AFFFFFF`、`PLAYER_ICON #F2F6FF`、`ACCENT #FF8FB1`、`ACCENT_SOFT #FFB3C8`、`TEXT_PRIMARY #F5F7FC`。

## 0. 结构

```
右上角 topActions（48×48 透明 hit wrapper）
└ MoreCapsule 44×40dp（圆角 20dp）
   └ 三点图标组 22×4dp（3 个 4dp 圆点，间距 5dp）
```
- 视觉 44×40dp，**点击热区 48×48dp**；视觉在 wrapper 内居中，四周各留 2dp/4dp 透明，不改变点击面积。
- 位置：距屏幕右上安全区/标题栏 `end 8dp`、`top 8dp`；不与返回按钮/标题相撞。

## 1. 容器

| 项 | 值 |
| --- | --- |
| 形状/直径 | **44×40dp 胶囊**（不是 48dp 正圆），圆角 **20dp** |
| 填充 | `PLAYER_CHIP #99000000` |
| 描边 | 1dp `STROKE_SOFT #1AFFFFFF` |
| 内边距 | 0（图标组居中） |
| 阴影/elevation | **0** |
| 模糊/发光 | 无 |
| 与中央三键关系 | 同 `PLAYER_CHIP` 底、同 1dp `STROKE_SOFT`、同圆角语言；尺寸更小，不再独立灰圆 |

验收：右上角是一个 44×40dp 玻璃小胶囊，不再是 48dp 圆；与中央三键的底色/描边/圆角同族。

## 2. 三点图标

| 项 | 值 |
| --- | --- |
| 形态 | 3 个水平排列的实心圆点 |
| 单点直径 | **4dp** |
| 点间距 | **5dp**（点中心间距 9dp） |
| 图标组尺寸 | 22×4dp，水平/垂直居中 |
| 颜色 | `PLAYER_ICON #F2F6FF`，不描边、不加外圈 |
| 圆头 | 圆点本身即圆头；禁止方形/椭圆/不同大小点 |
| 实现 | 新增 VectorDrawable 或自绘 3 个 4dp 圆，不复用旧 media3 「more」图标 |

验收：三个 4dp 等大圆点、间距 5dp、组宽 22dp，在 44×40 胶囊内居中，无旧图标残留。

## 3. 焦点态

| 项 | 值 |
| --- | --- |
| 焦点底 | `#1AFF8FB1`（10% ACCENT，叠在胶囊上） |
| 焦点描边 | 2dp `ACCENT_SOFT #FFB3C8`，内侧 |
| 焦点圆角 | 20dp（跟随胶囊） |
| 缩放 | 容器/焦点框**不缩放**；仅三点图标组 1.0→**1.04**（只 transform，不触发布局） |
| 动效 | 进 120ms `DecelerateInterpolator`；出 100ms；Reduced 即时 |
| 图标色 | 焦点仍 `PLAYER_ICON`，不染粉 |
| 按下态 | 叠 `#26FF8FB1` 80ms，不缩放、不位移 |

- 与底部文字按钮（10% 粉底 + 2dp `ACCENT_SOFT` 圆角框、120/100ms）同一语言；此处圆角 20dp 因容器是胶囊。
- 焦点框必须落在 44×40 视觉内，不越出 48×48 hit，不盖返回键/标题。
- 不得复用旧 `UiIcon` 聚焦 1.1× 缩放；焦点由专用渲染器控制，容器框固定。

验收：焦点时胶囊只加 10% 粉底 + 2dp 浅粉内框，三点仅放大 1.04，120ms 进/100ms 出，不溢出、不压到相邻控件。

## 4. 无障碍/状态

- contentDescription：「更多工具」；点击打开现有工具面板。
- 按钮在 TV/遥控模式可聚焦；触摸模式单击即响应；焦点链位于顶部「返回 ↔ 更多」，下键进入控制条。
- 当前播放/暂停状态不影响更多按钮外观。

## 5. 禁止

1. 48dp 正圆、半透明灰底、独立圆形底。
2. 三点不等大/间距不一致/加描边或外圈。
3. 复用旧 media3 more 图标或 1.1× 焦点缩放。
4. 焦点外发光、阴影、blur、elevation。
5. 焦点框超出 44×40、盖住返回键或标题。
6. 引入新颜色。

## 6. 验收一句话

右上角为 44×40dp `PLAYER_CHIP` 玻璃胶囊（1dp `STROKE_SOFT`、圆角 20dp、无阴影），内含 3 个 4dp/间距 5dp 的 `PLAYER_ICON` 圆点；焦点为 10% 粉底 + 2dp `ACCENT_SOFT` 内框、仅图标 1.04、120ms 进/100ms 出，不溢出、与中央三键同一语言。
