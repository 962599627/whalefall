# QA 角度的新功能建议（3 条）

> 背景：1.7.10 已发布；历史缺陷集中在播放页布局/触摸、壁纸生命周期、TV 焦点与返回、更新安装、网盘状态。建议围绕**可测性/稳定性/反馈闭环**，不新增内容能力。

1. **安全模式（崩溃自恢复）**｜预防：播放页/壁纸/TV 焦点类崩溃导致「一开就崩」的死循环（如 DEF-2013 R8 闪退、DEF-2024 壁纸盖播放器）。验证：注入崩溃/播放页连续旋转 20 次，连续 2 次崩溃后自动进安全模式（禁用壁纸与硬件叠层）并弹「恢复默认」入口；S。
2. **灰度发布 + 一键回滚**｜预防：更新安装后不可用（DEF-2013 R8 包闪退、DEF-2020/2021 播放页回归），只能靠用户手动换包。验证：feed 支持按 channel/百分比灰度；设置内「回滚到上一可用版本」→ 下载并校验旧包 sha 后安装成功；M。
3. **诊断闭环增强（布局/触摸/焦点事件轨迹 + 一键上报）**｜预防：播放页 inset/点按、壁纸生命周期、TV BACK 这类「必须现场看才知道」的问题反复返工（DEF-2020/2021/2023/2024/2017）。验证：开关开启后记录最近 N 条 layout/inset/tap/back/壁纸事件，导出诊断包（脱敏）含轨迹与版本 sha；用户一键上报；M。
