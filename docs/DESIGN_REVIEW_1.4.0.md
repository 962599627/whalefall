## 1. 入口位置与焦点顺序

### 1.1 现状（代码事实）

- `HomeDock` 固定 6 项：`首页 / 搜索 / 直播 / 收藏 / 网盘 / 设置`（`HomeDock.java:13–16`）；右 rail 宽 50、高 292dp、单元 38dp、间距 4dp（`:26–29`），标签是 rail 外侧气泡（`:55–66`），不占 rail 宽度。
- 「直播」打开 `LiveController` 的 M3U 简易列表（`MainActivity:1622–1629`），**不是**手机版电视台直播；TV 设置只有 4 项（`SettingsScreen:67–73`），无文件管理/崩溃日志/存储清理/关于/统计/遥控器说明。
- 容量测算：6 项实占 6×38+5×4+2×8=**264dp**（rail 292dp，余量 28dp）；7 项需 ≈306dp；8 项约 348dp、140% 时约 488dp，逼近 504dp 安全高 → **7 项安全，8 项不推荐**（Lead 已拍板 7 项）。

### 1.2 拍板方案（Dock +1「电视」，共 7 项）

- 顺序：`首页 → 搜索 → 直播 → 电视 → 收藏 → 网盘 → 设置`；「直播」保持 M3U 入口、「电视」打开电视台直播（TvLive 共享页，页内含「频道管理」）。
- 几何：cell 38、间距 4、图标 21、焦点标签 12sp **全部不变（等分同一节奏）**；rail 高 292→**306dp**（navScale 同比，140% 时约 428dp < 504dp 安全高）；焦点 tag 用保留键 `nav-tv`。标签为气泡、不挤占 rail 宽度，7 项不会横向挤爆。
- 「文件管理」等 4 项进 TV 设置页新增分组「本机与工具」，顺序：文件管理 → 管理员后台（手机/电脑）→ 查看崩溃日志 → 存储空间与缓存清理 → 观影统计 → 遥控器按键说明 → 关于鲸落；分组标题 13sp 不参与焦点。
- 焦点顺序（Dock）：上/下 = 首页→搜索→直播→电视→收藏→网盘→设置（`HomeDock:135–143` 的 nextFocus 链）；左 = 回内容区（`HomeDock.key():207–221`，homeReturnFocus→source-switcher→primary）；右 = 停在原地；内容右缘进「首页」图标（`HomeScreen.wireNavigation()`）。
- 进入/返回：OK 进入；BACK 回首页并还焦点（电视页→`nav-tv`、设置→`nav-settings`；设置子页→设置页对应行）；电视台直播播放页按 §2.2 逐级返回。

### 1.3 未采用方案（留档）

- 0 新增项（把「直播」直接升级为电视台直播）：会丢失现有 M3U 直播入口，与手机版「直播/电视」双 tab 不一致 → 不采用。
- Dock 第 7 项「工具」聚合页：多一层导航、工具入口不够直给 → 不采用；文件管理放设置分组即可。

## 3. 遥控不可用功能的降级（统一口径）

### 3.1 统一弹窗

- 标题：**需要手机或电脑操作**；正文：**「电视端不支持键盘输入、文件选择或剪贴板。请在手机/电脑浏览器打开「管理员后台」完成；完成后回到电视刷新即可。」**
- 按钮：「知道了」= 主按钮、**默认焦点**（按 OK 立即返回原页面）；「查看管理员后台」= 次按钮（可选，仅文件/频道/配置类显示）。沿用 `AppDialog` 时需显式把首焦点给「知道了」（其 message 默认可聚焦）。
- 形态：复用 `AppDialog` 玻璃卡（TV 500dp 宽、标题 23sp、正文 15sp、按钮 42dp）；BACK=关闭；关闭后焦点回触发控件。

### 3.2 触发清单

| 功能 | 处理 |
| --- | --- |
| 文件上传 / 本地文件选择（壁纸、配置、字幕） | 不弹系统选择器；弹统一弹窗（可带「查看管理员后台」） |
| 新建文件夹 / 重命名 / 频道改名改址 / 导入 JSON 文本 / 粘贴配置 | 不显示 EditText；弹统一弹窗 |
| 管理员后台网页表单 / FTP 设置 | 电视只展示 QR + 地址 + 令牌 + FTP 地址；不在电视上编辑 |
| 剪贴板类（复制崩溃日志 / 复制源码地址 / 粘贴配置） | **TV 无剪贴板**：隐藏或统一降级；崩溃日志改「另存到文件管理」 |
| 克隆/备份导出、还原 | 弹统一弹窗，不读剪贴板 |

### 3.3 不崩、不卡死

1. 所有降级入口**先弹窗后返回**，不得出现点击无反应；异常统一 catch → 弹窗/Toast，不闪退。
2. 管理后台/FTP 启动失败、文件目录读取失败、日志文件不存在：均给可读文案 + 「知道了」，焦点回原控件。
3. 不启动软键盘、不等待 onActivityResult 回调；异步操作期间按钮置灰，完成/失败后恢复。
4. 长按/重复按键不得重复触发弹窗或重复启动服务（同一时刻只允许一个 AppDialog）。

## 5. Lead 拍板（2026-11-09 22:5x）与已知偏差

- **拍板 1（入口）**：新增第 7 项「电视」= 电视台直播；现有「直播」（M3U）保留，两者不同功能。7 项等分同一节奏（cell 38/间距 4/图标 21/标签 12sp），rail 292→306dp；文件管理放设置页「本机与工具」，不动 Dock。

- **拍板 3（崩溃日志）**：**整页可滚动**，不做弹窗；复制改为「另存到文件管理」。
- **拍板 4（剪贴板）**：TV 无剪贴板，复制/粘贴类统一降级，不弹软键盘、不崩。
- **拍板 5（焦点）**：本轮新页面**沿用现有 FocusMotion（2dp 白描边）**，不做全局 3dp ACCENT 改造；**已知偏差**：新页面焦点态与 3dp ACCENT + 1.02× 目标不一致，记为 **1.5 后续项**（全 TV 统一，需单独立项）。

- 三端边界：本文所有值仅 TV；手机/平板沿用原规范。共享页改造后移动端必须截图回归（列表行高/字号/触控小按钮均不变）。
