# 字体颜色自定义弹窗 · UI/UX 规范（1.4.6）

> 范围：设置新增「字体颜色」：预设色板 + RGB 设置 + HEX（手机）；手机竖屏、TV 960×540 各一套。
> 依据：`WHALEFALL_DESIGN_SYSTEM.md`（token）、`DESIGN_REVIEW_1.3.0.md`（首页字面量清单）；代码：`AppDialog`（弹窗壳）、`UiTokens`、`SettingsScreen.appearance()`、`MobileShell` 设置外观页、`PlaybackControls.showSubtitleAdjuster()`（TV 方向键直调参考）。
> 约束：只写本文档；不改代码/其他 docs；不新增颜色 token；焦点沿用 FocusMotion 2dp 白描边；拿不准标「待确认」。

## 0. 结论（3 个关键决定）

| # | 决定 | 内容 |
| --- | --- | --- |
| 1 | **色板数量** | **9 格 = 1 默认 + 8 预设**，手机/TV 均 3×3；默认 `#F5F7FC`（＝`TEXT_PRIMARY`）。 |
| 2 | **RGB 步进** | 手机滑条连续 0–255（精度 1）；TV 左右 **±5**（长按连发），HEX 仅手机可精确输入。 |
| 3 | **推荐组合** | 做 **3 组**一键组合：默认月白 / 亮壁纸深灰 / 樱粉；只设主色，次要与弱文字自动派生。 |

## 1. 弹窗结构

### 1.1 手机竖屏（390×844）

| 项 | 规格 |
| --- | --- |
| 弹窗壳 | `AppDialog` 玻璃卡：宽 **屏宽−32（≈358dp，左右各 16dp 外边距）**，内容区最大高 **屏高−200（≈644dp）**、可滚动；圆角 28；标题 23sp bold「字体颜色」 |
| 副题 | 12.5sp `TEXT_SECONDARY`：「仅调整主要文字；强调色（樱花粉）不跟随」 |
| 预览 | 310×90dp、圆角 16、底 `SURFACE_1 #141C2A`；3 行样例（§3），实时刷新 |
| 推荐组合 | 3 个 40dp 胶囊横排（可换行）：默认月白 / 亮壁纸深灰 / 樱粉 |
| 色板 | **3×3、44dp 格、间距 12**；默认格 9sp「默认」角标；选中 2dp `ACCENT` 外圈 + 白色 ✓ |
| RGB | 3 行×38dp：`R/G/B` 13sp bold + 数值 13sp `tnum`（宽 48）+ 轨道 4dp/thumb 18dp；拖动实时预览 |
| HEX | 40dp 玻璃输入框、等宽 13sp、`#RRGGBB`；合法即预览，非法红描边 + 确定置灰 |
| 底部 | 「恢复默认」13sp `ACCENT_SOFT` 左置；取消/确定 44dp 胶囊；对比度提示 11.5sp（达标 `SUCCESS`／不足 `DANGER`） |

### 1.2 TV（960×540，安全边 24/18）

| 项 | 规格 |
| --- | --- |
| 弹窗壳 | `AppDialog` 玻璃卡：宽 **680dp**、内容高 ≈334（≤340 上限）、总高 ≈468 < 504 安全高；圆角 28；标题 23sp bold |
| 布局 | 左 300（预览+推荐+色板）/ gap 32 / 右 300（RGB+对比度+恢复默认）；无软键盘、HEX 隐藏 |
| 预览 | 300×96dp、圆角 16、底 `SURFACE_1`；3 行样例（§3） |
| 推荐组合 | 3 个 40dp 胶囊横排，左右切换、OK 应用 |
| 色板 | **3×3、48dp 格、间距 8**；默认角标 10.5sp；焦点格 2dp 白描边 + 现有 FocusMotion 缩放（不改布局） |
| RGB | 3 行×48dp：`R/G/B` 15sp bold + 数值 15sp `tnum`（宽 56）+ 轨道 6dp/thumb 20dp；**左右 ±5**、长按连发、实时预览 |
| HEX/底部 | HEX 隐藏（无键盘；可显示只读值 +「HEX 仅手机可输入」，待确认）；「恢复默认」44dp；取消/确定 44–48dp；对比度 13sp |

## 2. 交互

### 2.1 手机

- 点预设色块即选中：预览、RGB、HEX 同步；点「确定」才保存（未确定不写 prefs）。
- 拖动滑条实时预览；HEX 合法 6 位即预览，非法（非 0–9/A–F、长度≠6）标红、确定不可用。
- 「恢复默认」＝选中默认色并同步滑条/HEX，不关闭；取消 / 返回键 / 点遮罩＝关闭且不保存、恢复原色。
- 确定＝保存并 toast「字体颜色已更新」；对比度按 `BG #0B1220` 计算，<4.5:1 红字提示，确定前二次确认（默认「取消」，兼容亮壁纸深灰字）。

### 2.2 TV 遥控

- 首焦点：**当前颜色对应的预设格**；自定义色无匹配则落「默认」格（第一格）。
- 色板：左右移格、上下换行；**OK 选中**（预览/滑条同步，焦点留色块）；推荐组合同规则。
- 色板末行「下」→ RGB 首行（R）；RGB 内**上下换行**（R→G→B→恢复默认→取消/确定），**左右调值 ±5**（长按连发）。
- **OK 在滑条上＝结束调节并把焦点移到「确定」**（避免误保存）；按钮行 OK 执行；**BACK 任意位置＝取消不保存**，关闭后焦点回设置「字体颜色」行。
- 不弹软键盘、不展开 HEX；方向键不穿透到页面。

## 3. 预览样例文本

| 行 | 文案 | 字号/字重 | 颜色 |
| --- | --- | --- | --- |
| 1 | 鲸落 · 今晚看什么 | 17sp bold | **主色**（100%） |
| 2 | 第01集 · 继续播放 | 15sp regular | 主色 100% |
| 3 | 2026 · 中国大陆 · 剧情 | 13sp regular | **次要色＝主色 70% 不透明度**（自动派生） |

- 可加 11.5sp「说明文字示例」＝主色 **56%**（对应 `TEXT_TERTIARY`）；预览固定 3 行主样例。
- 派生只降不透明度、不换色相；`ACCENT #FF8FB1`、`SUCCESS`、`DANGER`、焦点白描边不跟随。
- 预览底固定 `SURFACE_1`；实际页面 `BG` 与玻璃卡两种底需肉眼对照（待确认是否加双底色预览）。

## 4. 覆盖范围与不做

- **本轮保证**：首页 / 片库 / 详情 / 设置 / 电视台直播 / 播放器的**主要标题与正文**（含按钮文字、列表行、说明、时间码）。
- **入口**：手机「设置 → 界面外观与偏好 → 字体颜色」（在「导航栏字体与按钮大小」后）；TV「设置 → 首页与壁纸 → 字体颜色」（在「界面大小」后），行右显示当前色点 + 摘要。
- **不跟随**：`ACCENT` 樱花粉、焦点描边（白）、`SUCCESS/DANGER`、海报角标、频道台标品牌色、播放器 chrome 底色/图标、直播 WebView。
- **硬编码后续覆盖**：首页卡片副标题 `#8E959E`、分类胶囊 `#F3F4F6`、筛选浮条、直播频道名 `#D6E1F0` 等（1.3.0 报告 §3 D-02），本轮不保证全部。
- **不做**：壁纸自动取色联动、分角色/分页面独立色、浅色模式、字体族/字号、主题包导入导出。
- **数据**：`0xRRGGBB` 单值存 prefs（新键），纳入备份/恢复与设置重置；默认 `#F5F7FC`；未确定不写入。

## 5. 推荐配色与色板

| 组合 | 主色 | 适用 |
| --- | --- | --- |
| 默认 · 月白 | `#F5F7FC` | 深海蓝默认背景，对比 17.3:1 |
| 亮壁纸 · 深灰 | `#2B313B` | 仅搭配亮色壁纸；默认暗底会提示低对比度 |
| 樱粉 · 柔粉 | `#FFB3C8` | 与 `ACCENT_SOFT` 同值但作为字体色，不改变强调色语义 |

- 9 格：默认月白 + 暖白 `#FFF1E0`、冷白 `#EAF3FF`、薄荷 `#DDF7EC`、浅金 `#FFE6B8`、樱粉白 `#FFE3EC`、雾蓝 `#C9D8EE`、象牙 `#F3EAD3`、灰白 `#D9E1EA`。
- 所有预设按 `BG #0B1220` 对比度 >10:1；自定义色 <4.5:1 走 §2.1 二次确认。

## 6. 复用 / TV 专用 / 待确认

- 复用：`AppDialog` 壳（玻璃/标题/按钮/焦点返回）、FocusMotion 焦点（2dp 白描边）、`UiTokens` 文字三级色、TV 字幕调节器的「方向键直调 + 实时预览」模式。
- TV 专用：色板/滑条焦点框、左右 ±5、无 HEX、无软键盘；手机专用：HEX、滑条连续拖动、点色块即选。
- 待确认：①次要色 70% / 弱文字 56% 透明度观感（截图对照）；②亮壁纸深灰字在暗玻璃卡上的提示逻辑（不做自动取色）；③备份/重置是否含新键；④TV HEX 是否显示只读值、手机横屏是否复用竖屏弹窗（建议复用）。
