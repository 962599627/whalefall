# IPTV 二级频道选择器 · 视觉规范（1.9.38）

> 范围：电视台 IPTV 的二级频道选择器（左分类 / 右频道列表）。目标：从三栏窄条 + 密集列表改为一张清晰的左右分栏玻璃面板，分类轻、频道好扫、播放/收藏状态一眼可辨。
> 只写规格，不碰代码。颜色只用现有 token：`BG_DEEP #070D18`、`STROKE #33FFFFFF`、`STROKE_SOFT #1AFFFFFF`、`TEXT_PRIMARY #F5F7FC`、`TEXT_SECONDARY #A9B7D0`、`TEXT_TERTIARY #8D9CB6`、`ACCENT #FF8FB1`、`ACCENT_SOFT #FFB3C8`、`PLAYER_ICON #F2F6FF`。

## 0. 结构（文字版）

```
Modal 背景遮罩 #66000000（手机可点外关闭；TV 不响应外点）
└ ChannelPickerPanel（居中，圆角 20dp，深蓝玻璃）
   ├ Header 48dp：标题「选择频道」+ 右侧关闭 32dp
   ├ Body（左右 1 : 2）
   │  ├ LeftRail（1/3）：全部 / 央视 / 卫视 / 地方 / 其他 + 数量
   │  └ RightList（2/3）：频道行（编号/名称/当前播放条/收藏心标）
   └ Footer 32dp：方向键 / OK / BACK 提示
```
- TV/平板：面板 **720×420dp**，左 **240dp**、右 **480dp**（1:2），居中，上下各留 60dp（540 屏）。
- 手机横屏：面板宽 92%、高 78%，左 1/3、右 2/3；手机竖屏：面板宽 `窗宽-24dp`、高 78%，左 1/3（最小 104dp）、右剩余。
- 面板外遮罩 `#66000000`；面板本身 **无全屏 blur、无大阴影**，层次靠 1dp 描边 + 深蓝玻璃。

| 描边 | 1dp `STROKE #33FFFFFF` |

验收：面板是一张 20dp 圆角深蓝玻璃卡，左右 1:2 分栏，无三层窄条、无大阴影。

## 2. Header（标题 + 关闭）

| 项 | 值 |
| --- | --- |
| 高度 | 48dp（手机 44dp） |
| 标题 | 「选择频道」；TV 16sp / 手机 15sp，bold，`TEXT_PRIMARY` |
| 标题位置 | 左 16dp；垂直居中 |
| 关闭按钮 | 32dp 圆形；图标 16dp `TEXT_PRIMARY`；背景 `#1AFFFFFF` + 1dp `STROKE_SOFT`；距右 10dp、上 8dp |
| 关闭焦点 | 2dp `ACCENT_SOFT` 内环 + 10% 粉底，圆角 16dp；120/100ms |
| 关闭点击区 | ≥40dp（视觉 32 + 透明 4dp） |

验收：标题清楚、关闭按钮在右上角不压标题，焦点可见且不越出 32dp 圆。

## 3. 左分类栏

| 项 | 值 |
| --- | --- |
| 栏宽 | 面板 1/3（TV 240 / 手机最小 104） |
| 内边距 | 上下 8dp、左右 8dp；分类项间距 4dp |
| 分类项高 | TV/平板 **44dp**；手机 **40dp** |
| 项圆角 | 10dp；左右内边距 10dp |
| 文字 | 14sp（手机 13sp）；未选 `TEXT_SECONDARY` |
| 数量 | 右对齐 11sp；未选 `TEXT_TERTIARY` |
| 选中态 | 底 `#1AFF8FB1`（10% 粉）；左侧 **3dp `ACCENT` 竖条**（高 24dp，贴左 4dp）；文字 `ACCENT_SOFT` bold；数量 `ACCENT_SOFT` |
| 焦点态 | 底 `#1AFF8FB1`；**2dp `ACCENT_SOFT` 内环**（圆角 10dp）；文字 `TEXT_PRIMARY`；不缩放 |
| 动效 | 进 120ms / 出 100ms Decelerate；Reduced 瞬时 |
| 选中+焦点 | 左条保留；焦点环叠加；同屏只一个焦点环 |

- 分类顺序固定：全部 → 央视 → 卫视 → 地方 → 其他；数量用 `全部 (N)` 或右侧小数字。
- 不用整块亮粉底、不用大于 10% 的粉色填充。

验收：选中项是「10% 粉底 + 3dp 左粉条 + 粉字」，焦点只是 2dp 内环；不遮住相邻分类。

## 4. 右频道列表

| 项 | 值 |
| --- | --- |
| 行高 | TV/平板 **48dp**；手机 **44dp** |
| 左右内边距 | 12dp；行间距 0，行间 1dp `#0FFFFFFF` 分隔线 |
| 编号 | 固定 30dp 宽，11sp `TEXT_TERTIARY`（可选：无编号时省略） |
| 频道名 | TV 15sp / 手机 13.5sp，`TEXT_PRIMARY`，**单行，超宽 `TruncateAt.END`**；不换行 |
| 名称可用宽度 | 右栏宽 − 编号 30 − 收藏 28 − 左右 padding 24；截断后保留完整 contentDescription |
| 当前播放标记 | 左侧 **3dp `ACCENT` 竖条**，高=行高−16dp；名称仍 `TEXT_PRIMARY`；不加整行粉底 |
| 焦点态 | 底 `#1AFF8FB1` + **2dp `ACCENT_SOFT` 内环**（圆角 10dp）；文字 `TEXT_PRIMARY`；不缩放、不位移 |
| 焦点动效 | 120ms 进 / 100ms 出 Decelerate；移出后底/环完全消失 |
| 收藏心标 | 右侧 16dp；未收藏=描边心 `TEXT_TERTIARY`，已收藏=实心 `ACCENT`；放在 28dp 热区内，**不进入焦点链**（长按 OK / 行操作切换） |
| 点击/OK | 立即播放；长按 OK 切换收藏；焦点不因播放消失 |

- 当前播放行 + 焦点：左条保留、焦点环叠加，二者不互相覆盖。
- 列表可滚动，隐藏滚动条；焦点滚动到可见；底部 Footer 固定不随列表滚动。
- 频道名禁止两行、禁止挤压收藏心标；超长显示 `…`，contentDescription 保留全名。

验收：焦点行有 10% 粉底 + 2dp 粉环；当前播放行有 3dp 左粉条；长频道名单行省略且心标完整。

## 5. Footer 提示行

| 项 | 值 |
| --- | --- |
| 高度 | TV/平板 32dp；手机 30dp |
| 文字 | 11sp `TEXT_TERTIARY`，居中 |
| TV 文案 | `←→ 切换分类   ↑↓ 选择频道   OK 播放   BACK 关闭` |
| 手机文案 | `左右切换分类 · 点按播放 · 返回关闭` |

## 6. 空态 / 加载态

### 6.1 空态（右栏）
- 垂直居中；无大插画。
- 标题：「暂无频道」14sp `TEXT_SECONDARY`。
- 说明：11sp `TEXT_TERTIARY`，如「换个分类看看，或稍后重试」。
- 错误可重试时：28dp 高玻璃胶囊「重试」（`#1AFFFFFF` 底 + `STROKE_SOFT`，字 `ACCENT_SOFT` 11sp，焦点 2dp 粉环）。
- 空态不改变左分类、Header、Footer。

### 6.2 加载态（右栏）
- 居中：20dp 圆环，2dp `ACCENT_SOFT` 弧段，轨道 3dp `#1AFFFFFF`，900ms 线性旋转；下方 8dp 处 11sp `TEXT_TERTIARY`「正在加载频道…」。
- `Prefs.REDUCED` 时显示静态 20dp 圆环 + 文案，不旋转。
- 加载态不阻塞左分类切换；切换后重新加载并保持左栏选中。
- 不用 96dp 角色帧动画（本选择器保持轻量）。

## 7. 焦点链与交互

- 打开时默认焦点：**右列表当前播放行；无当前行则第一项**；左/右方向键在分类与列表间切换；上下移动列表；BACK 关闭；OK 播放。
- 分类切换：更新右列表并回到列表第一项；当前播放标记保留在对应频道行（若存在）。
- 关闭按钮与列表同一焦点语言；TV 焦点顺序：左分类 → 右列表 → 关闭 → Footer 不聚焦。
- 返回：BACK 关闭面板，焦点回打开前的电视台入口。

## 8. 禁止

1. 三栏窄条/右侧信息栏挤在同一面板；只保留左右 1:2。
2. 白色/浅色大卡片、全屏 blur、重阴影。
3. 整块亮粉选中/整行粉底；选中与焦点都只允许 10% 粉底 + 3dp 左条/2dp 内环。
4. 频道名换行、挤压收藏心标或截断编号。
5. 焦点缩放/位移/外发光，或焦点环越出面板/行。
6. 空态/加载态使用大尺寸角色动画或遮住左分类。
7. 引入新颜色；只使用上述 token。

## 9. 验收清单（一句话）

- 面板为 720×420dp（TV）20dp 圆角深蓝玻璃，左 1:2 右分栏，Header/Footer 完整，无阴影。
- 左分类 44dp：选中=10% 粉底+3dp 左粉条+粉字；焦点=10% 粉底+2dp `ACCENT_SOFT` 内环。
- 右频道 48dp：名称单行省略、当前播放 3dp 左粉条、收藏心 16dp 状态清晰；焦点=10% 粉底+2dp 内环，不缩放。
- 顶部标题 + 右上 32dp 关闭；底部 32dp 方向键提示；空态/加载态轻量、只占右栏。
