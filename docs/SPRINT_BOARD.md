## 0. 状态图例与完成定义

| 状态 | 含义 |
|---|---|
| todo | 未开始 / 已排期 |
| doing | 有明确负责人正在做 |
| review | 改动已落地，等回归或等真机证据（**本轮主战场**） |
| blocked | 有外部阻塞，需 Lead / 产品拍板或环境支持 |
