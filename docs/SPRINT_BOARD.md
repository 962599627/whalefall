## 0. 状态图例与完成定义

| 状态 | 含义 |
|---|---|
| todo | 未开始 / 已排期 |
| doing | 有明确负责人正在做 |
| review | 改动已落地，等回归或等真机证据（**本轮主战场**） |
| blocked | 有外部阻塞，需 Lead / 产品拍板或环境支持 |
| done | 有可复核证据（构建产物 / 截图 / 录屏 / 日志） |

口径提示：V1–V5 目前只有用户口头确认 → 保持 review；S1-06/S1-13 有文件行级证据 → 可转 done；S1-07/S2-01 代码未提交 → 不转 review。
