## V25 播放页点按呼出可靠性（P1，DEF-2021，约 5 分钟）

1. 进播放页，等控制条**自动隐藏**。
2. 单击画面 **左 / 中 / 右 / 上 / 下** 五个位置，每处 2 次，**共 10 次**——期望 10 次都**立即**呼出（不用等、不用点第二下）。
3. 隐藏态**快速连点 5 次** → 只应呼出控制条，**不得把视频暂停**。
4. 显示态单击画面 → 控制条应隐藏。
5. 双击画面 → 暂停/继续仍正常。
6. 拖动进度条 / 左右滑（亮度音量/快进）/ 长按倍速 → 都不受影响。
7. **旋转一次**（竖→横）后重复第 2–3 步。

- 期望：显隐跟手；连点不误触暂停；原有手势（双击/拖动/滑动/长按）不被破坏。
- 证据：`mobile-V25-1.mp4`（30s，覆盖第 2–7 步）。
- **不通过**：10 次里有 1 次没立即出现 / 连点导致暂停 / 显示态点不掉 / 双击或拖动/滑动/长按失效 / 旋转后复发。
- 异常时补：「设置 → 运行日志」里与播放器相关的日志截图 `mobile-V25-log.png`。

## V26 运行日志复制/导出（P2，DEF-2022，约 2 分钟）

- **手机**：设置 → 运行日志 → 点「**复制**」→ 回桌面打开记事本/输入框粘贴，**能粘出日志内容**（不是空/不是旧剪贴板内容）。
- **TV**：设置 → 运行日志 → 点「**另存到文件管理**」→ 打开文件管理，能看到 `运行日志-*.txt`。
- 另外确认：清空仍是**二次确认**，弹窗仍可「关闭」。
- 证据：`mobile-V26-1.png`（粘贴结果截图）、`TV-V26-1.png`（文件管理里文件名）。
- **不通过**：复制粘贴为空 / TV 另存后文件管理找不到 `运行日志-*.txt` / 清空没二次确认。
