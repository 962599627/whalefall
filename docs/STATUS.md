# 功能与验证范围

当前版本：0.4.15 Preview。预览版不等于全设备、全配置兼容。

## 当前能力矩阵

| 模块 | 当前支持范围 | 已知边界与限制 |
|---|---|---|
| 配置导入 | 局域网手机扫码/网页表单推送、遥控器 HTTP(S) 地址输入、本地 JSON 文件导入、设置与配置备份还原 | 不内置、不提供、不托管任何配置地址或影视资源；本地文件操作依赖系统文件选择器 |
| 点播来源 | 标准 JSON CMS（`type=1`）、实验性普通 `csp_` JAR 插件（`type=3`，需手动开启）、QuickJS 脚本源 | 混淆/加壳或强绑定特定宿主私有实现的第三方插件不保证兼容 |
| 全局搜索 | 内置全拼/首拼词库与已浏览标题学习、多源并发有界调度、单源超时隔离与重试、目录型结果继续展开 | 拼音词库为有限静态词表 + 本地学习，不保证所有生僻缩写均可反查 |
| 播放器与解码 | Media3（含 FFmpeg 音频、dav1d AV1、libvpx VP9 软解扩展）与系统播放器切换、SurfaceView/TextureView 切换、长按加速快进快退、小窗选集、片头片尾跳过、倍速、音轨/外挂字幕、XML/JSON 弹幕 | 4K/HDR 表现取决于电视硬件解码器；合成样本验证不代表所有真实片源或功放透传场景 |
| 直播与磁力 | M3U / TXT 直播源解析、频道分组、上下台/数字键选台、失败自动切源；`magnet:?` 顺序分片校验流式播放 | 磁力播放需 Android 8.0+（API 26+）且受限于种子连接数与本机可用缓存空间 |
| 应用内更新 | 镜像与 GitHub 双源版本检查、断点续传、SHA-256 摘要校验、包名/版本递增/同签名证书校验、用户确认后调用系统安装器 | 仅对同签名更新包放行；不静默后台安装 |
| 多端自适应与跨平台 | Android 端同一 APK 自动识别电视（遥控器横屏）、平板（分栏大屏）与手机（竖屏底部导航 + 播放器全套触控手势）；`flutter/` 跨平台工程支持 Windows、macOS、iPhone 与 iPad，并与安卓端互通 `marco-movie-backup` 备份 | Flutter 端支持标准 JSON CMS 点播源与 M3U/TXT 直播源，不支持 Android 专属 `.jar` 插件 |

## 0.4.15 验证范围

最终候选在同一 Android 9 电视通过 139 项定向检查：详情与排序 25、播放器交互 75、搜索与续播 39。200 集合成样本覆盖右侧独立滚动、左侧海报固定且完整可见、倒序第一组、倒序跨组、切回正序后保留同一集与焦点，以及已有加载取消、网页解析与播放流程。本轮没有重跑全部电视显示配置或第三方来源，旧版范围保留为历史记录。

音量为 0，结束保持电视开机。

过往版本（0.3.0 – 0.4.14）的逐轮验证范围已归档至 [历史版本验证记录](history/VERIFICATION_HISTORY.md)，公开合规检查见 [PUBLICATION_CHECKS.md](PUBLICATION_CHECKS.md)，性能与帧率基线见 [EXPERIENCE_REVIEW.md](EXPERIENCE_REVIEW.md)。

为保护私有配置和内容信息，真实服务名称、测试影片、播放地址、账号状态和带内容画面的截图不随仓库发布。本地自动检查使用模拟数据；没有这些真实记录并不意味着可对所有服务作出保证。

## 仍在完善

全部网盘授权流程、任意扩展或直播列表、长时间播放、所有解码器、DRM 授权样本和磁力视频的电视端表现均未完成穷尽验证。配置导入成功不等于可用；第三方服务还可能随时变更。

持久媒体缓存、渲染视图切换等尚未完成。某些文件操作依赖电视的系统文件选择器。不会把未实现功能作为已有能力展示。
