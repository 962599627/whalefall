## 1. V21 TV 文件管理返回（P1，DEF-2017）

1. TV → 设置 → **文件管理**。
2. 点左上**返回箭头** → 应回到设置页。
3. 再进文件管理，按遥控器 **BACK** → 应回到设置页。
4. 进一个子目录 → 返回箭头 / BACK 应**逐级回上一级**（不跳回文件页）。

- 期望：不重复叠页；每次返回都真的上一级；最后能回到设置。
- 证据：`TV-V21-1.mp4`（20s，含返回箭头 + BACK + 子目录）。
- **不通过**：点返回又回文件页 / 反复按也退不出 / BACK 直接退出 App。

## 2. V22 TV 详情页新布局（P2，DEF-2018）

1. TV 首页 → 任一影片 → 进详情。
2. 对照 `docs/DESIGN_REVIEW_1.4.1.md` 与平板版：**左海报 + 播放浮层 / 右信息 + 操作按钮 / 下方线路 + 选集两列网格**。
3. 遥控 DPAD 走一遍焦点顺序：首焦点应在播放按钮，向下能到线路/选集，左右切换正常。
4. 按 OK 播放 → 返回详情 → 记位置。

- 期望：布局与平板版一致；焦点可见、顺序合理、无死区；播放可达。
- 证据：`TV-V22-1.png`（布局全图）+ `TV-V22-2.mp4`（20s，DPAD 走查 + 播放）。
- **不通过**：布局未对齐 / 选集仍是 5 列 / 焦点乱序或不可达 / 播放点不到。

## 3. V23 电视台直播页显示用户壁纸（P2，DEF-2019，手机 + TV）

1. 先在首页确认**已设置用户壁纸**（能看到壁纸）。
2. 进**电视 tab**，看页面背景：应透出用户壁纸（与首页/片库一致），不是整片深色渐变。
3. 看可读性：标题/频道列表文字、glass 面板是否清晰；右侧 Dock 区域与主区域过渡自然。

- 期望：壁纸可见 + 文字/面板可读；不应为了透壁纸把内容做糊。
- 证据：手机 `mobile-V23-1.png`、TV `TV-V23-1.png`。
- **不通过**：仍看不到壁纸 / 壁纸出来了但文字或面板看不清 / Dock 与内容色差明显割裂。
