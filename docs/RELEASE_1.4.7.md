## 本版内容

1. **网盘登录状态三态真实检测**（DEF-2028）：
   - 可确认的登录信号：本地凭据（凭据键 + 值形态）、来源 WebView 登录 Cookie（夸克 `__puus`、UC `_uc_s`、百度 `BDUSS`、阿里 `refresh_token` 等）、来源 prefs 凭据型 token；
   - 无法确认时显示「由源管理 · 无法读取」并说明「不等于未登录」，**不再显示假「未登录」**；
   - 普通站点 Cookie 只提示「有站点 Cookie，但无法确认登录」；
   - 检测改为后台扫描 + 一次快照 + 60s 缓存，两个面板共享；显式「刷新登录状态/刷新源状态」强制重新检测。
2. **修复本地凭据判据过宽**（架构复核 M1 及其残余）：只认凭据键 + 值形态（cookie 串或 ≥16 位 token），排除 `alias/quality/original/name/title/desc`；来源 prefs 任意键不再算本地凭据。
3. **其它复核修正**：更新包体文件名固定 `android-mobile`/`android-tv` edition 前缀（U1）；字体颜色「恢复默认」只重置预览、点确定才保存（T1）；对比度 <4.5:1 二次确认（T2）。
4. 含 1.4.6 网盘登录入口统一（先我们的玻璃面板、源面板前确认）、1.4.5 播放页壁纸遮挡修复/更新多包体/字体颜色、1.4.4 壁纸生命周期、1.4.3 播放页点按与铺满等全部内容。
