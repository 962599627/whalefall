## 本版内容

1. **修复播放页点按呼出控制条不灵敏**（DEF-2021）：控制条隐藏时单击画面立即呼出（不再等 300ms 双击判定）；快速连点只呼出、**不再误触发暂停/播放**；已显示时单击隐藏、双击暂停/继续保持原行为；拖动进度/左右滑/长按倍速不受影响。
2. **恢复布局稳定**：播放页只在窗口尺寸真实变化时重排控件与重铺视频，去掉 1.4.2 的连续布局（避免触摸时序受影响）。
3. **运行日志可复制/导出**（DEF-2022）：手机加「复制」到剪贴板；TV 加「另存到文件管理」（`诊断/运行日志-*.txt`）；清空前二次确认。
4. 含 1.4.2/1.4.1/1.4.0 全部内容：播放页铺满/贴边与视频重铺、TV 文件管理返回、TV 详情页平板式两栏、直播页壁纸透出、1.4.0 修复与 TV 功能对齐、首页虚拟化等。
