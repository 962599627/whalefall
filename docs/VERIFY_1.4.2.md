## V24 手机播放页铺满（P1，DEF-2020，约 3 分钟）

1. 首页/片库 → 点**集数**或「继续播放」**直进**播放页（横屏）。
2. 看：视频是否铺满；顶部返回/标题/清晰度/⋯、右侧时钟/影片结束、底部进度+10 图标行是否**贴屏幕边**（设计 16dp 安全距），有没有「卡片感/内缩」。
3. 切换**画面比例**（裁剪 / 适应）后再看一次。
4. **返回再进一次**；再**旋转一次**（竖→横→竖）复看。

- 期望：视频铺满；三组控件贴边整齐、不内缩；比例切换与旋转后不回到旧尺寸。
- 证据：`mobile-V24-1.png`、`mobile-V24-2.mp4`（20s，覆盖比例切换 / 返回再进 / 旋转）。
- **不通过**：仍有内缩或「卡片感」/ 控件贴内边缘（没到屏幕边）/ 底部图标行不满宽 / 比例切换或旋转后错位。
- 异常时补：设置 → 运行日志里 **`Player` 开头**那条 layout 诊断日志截图 `mobile-V24-log.png`。
