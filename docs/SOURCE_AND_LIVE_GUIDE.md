# 片源与直播配置：傻瓜式教程

> 本文只讲「怎么自己做一个配置、怎么导入」；不提供任何影视资源地址。请只使用你有权访问的内容。

## 一、片源配置是什么

一个「片源配置」就是一个 JSON 文件，告诉 App：去哪些站点找片、怎么搜索、怎么取播放地址。

TVBox / CatVod / 影视仓 类配置基本都能直接用。最小结构：

```json
{
  "sites": [
    {
      "key": "demo",
      "name": "示例站点",
      "type": 1,
      "api": "https://example.com/api.php/provide/vod/",
      "searchable": 1
    }
  ]
}
```

字段说明：

| 字段 | 含义 |
| --- | --- |
| `key` | 唯一标识，随便起英文名 |
| `name` | 显示在片源列表里的名称 |
| `type` | `1` = 苹果CMS 接口（最常见）；`0` = 直接 JSON 接口 |
| `api` | 站点接口地址，通常以 `/provide/vod/` 结尾 |
| `searchable` | 是否参与全局搜索，`1` 参与 |
| `ext` | 部分站点需要的额外参数（没有就不写） |

> 需要 JS / PY / JAR 插件才能运行的 `csp_` 片源，属于「扩展片源」，要另外的插件文件；
> 本 App 支持通过 JAR / JS / PY 运行，但插件本身需要你自行准备并确认合法。

## 二、怎么导入片源

设置 → 片源与直播配置 → 任选一种：

1. **从剪贴板一键粘贴**：把 JSON 或配置网址复制到剪贴板，点它即可
2. **输入或修改配置网址**：填 `https://.../config.json`，支持 JSON / JS / PY / TXT / M3U / ZIP
3. **选择本地文件**：从手机文件里选 `.json / .js / .py / .txt / .m3u / .zip`
4. **电视端**：同一局域网手机扫码推送，或用遥控器输入
5. 导入后在「切换默认片源」里选中它

## 三、电视直播配置

支持三种格式：

**1) M3U（最常见）**

```
#EXTM3U
#EXTINF:-1 group-title="央视",CCTV-1 综合
http://example.com/live/cctv1.m3u8
#EXTINF:-1 group-title="卫视",湖南卫视
http://example.com/live/hunan.m3u8
```

**2) TXT（group,#genre# 分组）**

```
央视,#genre#
CCTV-1 综合,http://example.com/live/cctv1.m3u8
CCTV-2 财经,http://example.com/live/cctv2.m3u8
卫视,#genre#
湖南卫视,http://example.com/live/hunan.m3u8
```

**3) JSON**：按 App 导入提示里的字段填写即可。

导入位置：设置 → 片源与直播配置 → **导入或管理电视直播源**。
导入后：电视 tab 左侧切分组，点频道即播；长按频道可收藏。

## 四、常见问题

- **导入成功但首页没内容**：先确认「切换默认片源」选中了它；部分站点需要额外 `ext` 参数
- **提示需要扩展引擎 / 插件**：这是 JS/PY/JAR 类片源，需要插件文件，不是配置 JSON 能解决的
- **搜索没有结果**：检查站点 `searchable` 是否为 1，以及该站点接口是否支持关键词搜索
- **直播 403 / 打不开**：源地址过期或限制地区，换源即可；App 不提供、也不代理任何直播源
- **配置打不开**：确认网址是直链（浏览器打开能看到 JSON，而不是网页）

## 五、安全提醒

- 只用你自己信任、且有权访问的配置与插件
- 配置里如果带账号/密钥，导入前先确认来源可靠
- 本 App 只是播放器：不内置、不提供、不托管任何影视资源

## 六、电视 tab 的「导入频道列表」怎么用

电视 tab 左下角有「＋ 添加」和「导入」两个按钮：

- **＋ 添加**：手动加一个频道（填名称 + 直播地址）
- **导入**：粘贴一段 JSON 或 M3U/TXT 文本，一次导入多个频道

导入弹窗支持的 JSON 格式（就是弹窗里的示例）：

```json
{
  "channels": [
    {"name": "CCTV-1 综合", "url": "https://example.com/live/cctv1.m3u8"},
    {"name": "湖南卫视", "url": "https://example.com/live/hunan.m3u8"}
  ]
}
```

完整流程：

1. 打开 App → 底部「电视」tab
2. 点左下角「导入」
3. 把上面的 JSON（或 M3U / TXT 内容）粘贴进输入框，点「导入」
4. 导入后频道出现在对应分组；点一下直接播放，长按可收藏
5. 想批量维护/更换源：设置 → 片源与直播配置 →「导入或管理电视直播源」

注意事项：

- 地址必须是能直接播放的直播流（`.m3u8` / `.flv` / `.mp4` 等），网页地址播不了
- JSON 里 `channels` 是数组，每个元素只要 `name` 和 `url` 两个字段
- 直播源会过期、限地区，遇到 403/黑屏换源即可
