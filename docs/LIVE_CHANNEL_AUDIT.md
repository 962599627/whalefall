## 4. 风险与口径（给 Lead 对外表述用）

1. **不承诺可播率**：本审计只核对「URL 类型是否为官方直播页 / 地址是否还指向正确官网」，**没有真机播放**。可播/黑屏/需登录/地域限制这一列 E2-S1 要求的信息本轮**未采集**，不得对外写「已全部验证可播」。
2. **不内置、不托管、不代理任何直播源**；不自动抓取新地址（与 `PRODUCT_BACKLOG.md` E2-S1「不做什么」一致）。
3. **外部变更不可控**：卫视官网改版、临时下线、地域限制、登录墙都会让地址失效，本次结果「截至 2026-11-09 检索」。
4. **WebView 差异**：官方页可能要求特定 UA、纯前端路由、先点「确定/播放」；本机为小米平板 M367FC（Android 17），其他机型表现可能不同。天津天视网页面用 SopCast 插件，属于**确认不可用**的形态。
5. **合规优先**：找不到官方直播页时，**保留官网首页**优于填聚合站/直连 m3u8（后者侵权风险 + 失效更快）。这也是本轮 15 条「维持现状」的理由。
6. **未真机验证**：所有「高/中/低」置信度只针对地址核实，不代表播放验证。
