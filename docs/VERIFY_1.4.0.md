# 1.4.0 真机验证清单

> 版本：**1.4.0**（versionCode 以 `android/version.properties` 为准，Lead 公告）｜包与 sha 由 Lead 公布
> 证据目录：`/sdcard/Download/DSH-Go/鲸落/verify/1.4.0/`（Lead 建）｜相关：`docs/VERIFY_1.3.1.md`、`docs/DEFECTS.md`
> 口径：**未验证不得宣称已修复/已优化**；TV 没有设备就写「未覆盖」，不许写通过。

## 0. 这版验什么

- **手机**：1.3.1 的三处修复随 1.4.0 延续（DEF-2010 浮层 / DEF-2011 顶部按钮 / DEF-2012 点频道转屏错乱），按 V9/V12/V13 **重拍**；首页虚拟化若 1.3.0 没测，这次补 V6。
- **TV**：TV 版四项功能 → V14 电视台直播、V15 设置「本机与工具」、V16 TV 冒烟。
- **R8**：DEF-2013（R8 包启动闪退）修复后重出的 R8 包 → V17。

## 1. 手机组（装 `WhaleFall-1.4.0-android-mobile.apk`）

### 1.1 V9 / V12 / V13（沿用 1.3.1 口径，全部重拍）

- **V9 直播浮层**：电视 tab → CCTV-2 → 等画面出 → 浮层 1s 内消失；再切 3 台（含央视+卫视）重复。证据 `mobile-V9-1.mp4`（20s）。
- **V12 顶部按钮**：电视 tab 竖屏/横屏各看一次——「＋自定义 / 导入列表 / 管理」完整可见可点。证据 `mobile-V12-1.png`（竖）、`mobile-V12-2.png`（横）。
- **V13 点频道与退出**：竖屏点 CCTV-2 → 播放器立即出现、横屏正常（不再出现「五按钮挤右边 + 三段式」）→ BACK 回电视 tab 竖屏正常、Dock 回来、无右侧竖栏 → 再进一次。证据 `mobile-V13-1.mp4`（20s）。
- 详细操作与不通过判定见 `docs/VERIFY_1.3.1.md` §1/§4/§5。

### 1.2 V6 首页虚拟化（若 1.3.0 未测则必测）

- 快速上下滑 10s → 停手 1s 看海报补齐 → 滚到底只加载一页 → 进详情返回/切 tab 位置误差 ≤1 行 → 重复 3 次。
- 证据 `mobile-V6-1.mp4`（30s）+ `mobile-V6-2.png`（设置 → 运行日志搜「首页虚拟化」的原始行）。

## 2. TV 组（装 `WhaleFall-1.4.0-android-tv.apk`，需 TV/盒子；没有就写「未覆盖」）

### V14 电视台直播（约 3 分钟）

1. Dock 第 7 项「**电视**」→ 选 **CCTV-1** → 遥控器 **OK** 播放。
2. 看画面/方向/全屏；按 **BACK** 回列表。
- 期望：能起播、画面正常；BACK 回列表不退出 App。
- 证据：`TV-V14-1.mp4`。不通过：黑屏/无法起播/back 直接退出。

### V15 设置「本机与工具」（约 5 分钟）

1. 设置 → 本机与工具：**文件管理 / 崩溃日志 / 存储清理 / 观影统计 / 遥控器说明**（5 页）逐页进。
2. 再看「关于」与「管理员后台（只读）」。
- 期望：DPAD 焦点可见、能移动；每页 BACK 逐级返回、不退出 App；不空白、不崩。
- 证据：`TV-V15-1.png` ~ `TV-V15-5.png`（可合并为 5 张）。不通过：进不去/焦点丢失/BACK 退出 App。

### V16 TV 冒烟（约 5 分钟）

1. 首页 → 搜索 → 直播 → 收藏 → 网盘 → 设置 六个入口各进一次、各返回一次。
- 期望：不崩、不白屏、焦点不丢；与 1.3.1 TV 版比无回归。
- 证据：`TV-V16-1.mp4`（30s）。不通过：任一入口崩溃/白屏/回不去。

## 3. R8 包（V17，等 Lead 重出 R8 包后再测）

装重出的 `WhaleFall-1.4.0-android-mobile-r8-arm64.apk`（**旧 1.3.1 R8 包已确认闪退，别再测**）：

1. 冷启动进首页（验证 DEF-2013：不再 `NoClassDefFoundError`）。
2. 首页图片正常加载 → 进详情 → 播放一段 → 退出。
- 期望：不闪退；首页/详情/播放与主包行为一致；重点看片源扩展引擎是否可用。
- 证据：`r8-V17-1.mp4`；若崩溃补 `r8-crash.png`。不通过：任何闪退/白屏。

- **V9/V12/V13** 对应 DEF-2010/2011/2012；**V17** 对应 DEF-2013；没验就保持「已修待验证/待重出包」。
