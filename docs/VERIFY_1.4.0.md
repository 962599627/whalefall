# 1.4.0 真机验证清单

> 版本：**1.4.0**（versionCode 以 `android/version.properties` 为准，Lead 公告）｜包与 sha 由 Lead 公布
> 证据目录：`/sdcard/Download/DSH-Go/鲸落/verify/1.4.0/`（Lead 建）｜相关：`docs/VERIFY_1.3.1.md`、`docs/DEFECTS.md`
> 口径：**未验证不得宣称已修复/已优化**；TV 没有设备就写「未覆盖」，不许写通过。

## 0. 这版验什么

- **手机**：1.3.1 的三处修复随 1.4.0 延续（DEF-2010 浮层 / DEF-2011 顶部按钮 / DEF-2012 转屏错乱）→ V9/V12/V13 重拍。
- **手机新增三条 UI**：DEF-2014 操作行靠左 / DEF-2015 右侧面板「收藏频道」完整 / DEF-2016 切 tab 回来不宽屏三栏 → **V18/V19/V20**。
- **首页虚拟化**若 1.3.0 没测，这次补 V6。
- **TV**：V14 电视台直播 / V15 设置「本机与工具」/ V16 TV 冒烟（没设备 → 三条都「未覆盖」）。
- **R8**：DEF-2013 修复后重出的 R8 包 → V17。

## 1. 手机组（装 mobile 主包）

### 1.1 V9 / V12 / V13（沿用 1.3.1 口径，全部重拍）

- **V9 直播浮层**：电视 tab → CCTV-2 → 等画面出 → 浮层 1s 内消失；再切 3 台（含央视+卫视）重复。证据 `mobile-V9-1.mp4`（20s）。
- **V12 顶部按钮**：竖屏/横屏各看一次——「＋自定义 / 导入列表 / 管理」完整可见可点。证据 `mobile-V12-1.png`（竖）、`mobile-V12-2.png`（横）。
- **V13 点频道与退出**：竖屏点 CCTV-2 → 播放器立即出现、横屏正常（不再「五按钮挤右边 + 三段式」）→ BACK 回电视 tab 竖屏正常、Dock 回来、无右侧竖栏 → 再进一次。证据 `mobile-V13-1.mp4`（20s）。
- 详细步骤与不通过判定见 `docs/VERIFY_1.3.1.md` §1/§4/§5。

### 1.2 V18 / V19 / V20（1.3.1 新报 UI，1.4.0 复验）

- **V18 操作行靠左**：电视 tab 竖屏 → 标题下方三个按钮应**靠左整齐**、完整可见可点（不是右对齐）。证据 `mobile-V18-1.png`。
- **V19 横屏面板收藏**：CCTV 频道播放（横屏）→ 右侧信息面板**滚到底** → 「♡ 收藏频道」完整可见可点 → 返回竖屏。证据 `mobile-V19-1.png`。
- **V20 切 tab 回电视（重点复现路径）**：竖屏电视页 → 点频道播放 → BACK 回竖屏 → 再去片库 → 切回电视，**反复 3 次**；全程单列、底部 Dock 不遮内容。证据 `mobile-V20-1.mp4`（30s）。

### 1.3 V6 首页虚拟化（若 1.3.0 未测则必测）
